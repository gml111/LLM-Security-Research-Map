# 《BadNets: Identifying Vulnerabilities in the Machine Learning Model Supply Chain》-2017
## 问题：问题场景、问题描述、问题挑战
1. **问题场景**
机器学习模型存在供应链风险，模型训练外包、使用第三方预训练模型做迁移学习十分普遍；使用者仅获取最终模型，无法管控训练流程，攻击者可在训练阶段投毒植入隐藏后门，威胁自动驾驶等图像识别系统。

2. **问题描述**
攻击者通过污染训练数据集得到后门模型BadNet。模型处理干净样本时分类性能正常；输入携带触发器的样本，则输出攻击者指定恶意标签。需要验证该后门攻击可行性，以及后门在迁移学习后的留存能力。

3. **问题挑战**
- 隐蔽性：不能破坏模型正常性能，无法修改网络结构，仅依靠数据投毒让模型习得后门行为；
- 迁移性：真实场景大量使用迁移学习微调，后门需要在微调后仍可生效；
- 现实可行性：触发器不能仅限于数字像素，需要支持物理世界场景。

> 对应基本要求：交代实际应用场景（外包训练、迁移学习、自动驾驶识别）；清晰准确描述后门威胁行为；点明挑战根源，讲清难点成因。

## 现有工作及不足：现有工作核心思路、存在的问题及根本原因
1. **现有工作核心思路**
已有投毒相关研究分为两类，一类是推理阶段的对抗样本，在测试样本上加扰动实现欺骗；另一类传统训练投毒，目标是直接降低模型整体分类精度。

2. **存在的问题**
对抗样本攻击发生于测试阶段，需要逐份修改测试样本，无法固化进模型权重；传统训练投毒会造成模型整体性能下降，极易被使用者发现。

3. **根本原因**
现有工作缺少针对模型供应链的威胁建模，没有研究“模型权重内嵌入隐藏后门，正常输入表现正常，仅特定条件触发恶意行为”这一问题。

> 对应基本要求：现有工作思路总结到位；清晰点出现有方法缺陷，完成背后根本原因分析。

## 方案：方案的动机、方案整体思路、方案关键步骤、关键技术
1. **方案动机**
现有攻击无法适配供应链场景，攻击者希望将恶意能力固化进模型权重，平时隐藏，遇到触发器才激活，因此提出基于训练集投毒的BadNets后门攻击。

2. **方案整体思路**
攻击者篡改部分训练样本，叠加触发器并修改标签为目标类别，使用污染数据集训练CNN；得到的后门模型在干净样本正常预测，带触发器样本输出指定标签；同时验证数字、物理触发器，测试迁移学习下后门存活情况。

3. **关键步骤**
1. 构造投毒数据集：部分样本叠加触发器，修改标签为攻击者目标标签，其余样本保持原样；
2. 使用污染数据集训练CNN，不改动网络架构；
3. 评估干净样本精度与后门攻击成功率；
4. 拓展验证：开展物理世界触发器实验，模拟迁移学习流程检验后门留存效果。

4. **关键技术**
- 数据投毒植入后门：不修改网络结构，依靠污染训练数据，让网络同时学习正常分类任务与触发器‑目标标签的映射；
- 数字‑物理双域触发器：数字端修改图像像素；物理端使用贴纸触发器，模拟真实拍摄带来的噪声；
- 迁移学习后门留存验证：通过冻结、微调不同网络层，观测后门存活状态。

> 对应基本要求：自上而下、先总后分，每一部分明确解决的问题，说明分析逻辑与具体实现方式。

## 实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
1. **实验数据**
MNIST手写数字数据集、GTSRB交通标志数据集，用于模拟通用图像识别与自动驾驶场景。

2. **对比方法**
以干净数据集训练得到的正常模型作为基线；开展消融实验，对比不同投毒比例、触发器样式、迁移学习配置下模型效果。

3. **评价标准**
- 干净样本准确率：衡量后门模型正常任务性能，表征攻击隐蔽性；
- 攻击成功率：带触发器样本输出攻击者目标标签的占比，衡量攻击有效性。

4. **参数设置**
采用基础CNN卷积网络；调节投毒样本占比；设置像素斑点、角落方块两类触发器；迁移实验区分冻结卷积层、微调全部网络等配置；完成实物打印触发器的物理场景测试。

5. **实验数据及分析**
1. 主实验：少量投毒样本就可以实现很高攻击成功率，后门模型干净样本准确率和正常模型几乎持平，验证攻击有效且隐蔽。
2. 投毒比例消融：投毒样本占比越高，后门攻击成功率越高。
3. 物理实验：贴纸触发器经过相机拍摄后依旧可以触发后门，证明威胁不只存在数字仿真环境，现实世界可实现。
4. 迁移学习实验：冻结卷积层做迁移学习，后门大部分保留；即便微调全部网络，后门也不会完全消失。

> 对应基本要求：实验设置合理完备，实验结果与前文提出的方案优势相互印证，证实供应链下后门威胁真实存在。





# 《Trojaning attack on neural networks》-2018
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当下预训练模型开源共享生态成熟，模型仓库、第三方开源权重广泛流通；攻击者可直接下载成品神经网络，无权限接触模型原始训练数据集、无法干预原始训练流程。现有后门攻击（如BadNets）依赖污染原始训练集，仅适用于外包训练场景，无法覆盖“下载现成模型投毒”这一主流供应链风险，人脸识别、自动驾驶、语音识别等关键系统极易被植入隐藏木马。

### 2. 问题描述
提出**无原始训练数据的神经网络木马攻击（TrojanNN）**：攻击者仅获取完整成品模型，不持有原始训练集，通过模型逆推生成专属隐蔽触发器、合成替代训练数据，二次微调模型植入隐藏恶意逻辑；干净输入下模型精度几乎无损失，携带触发器的输入会强制输出攻击者指定目标类别，同时后门可在迁移学习后保留，突破传统后门攻击的数据依赖限制。

### 3. 问题挑战
1. **数据缺失约束**：原始训练集不公开，无法采用传统训练集投毒方案，必须凭空生成等效训练样本；
2. **隐蔽性约束**：植入木马后，干净样本精度下降幅度极低，甚至可优化原始模型精度，规避基于验证集的人工筛查；
3. **触发器可控性**：需要生成人眼难以察觉、适配图像/音频/文本多模态的微小触发器，不能破坏正常输入观感；
4. **迁移鲁棒性**：用户微调预训练模型做下游任务时，后门行为不能完全消失；
5. **底层适配**：增量学习仅微调少量权重，无法稳定植入强后门关联，需要设计全新权重更新策略。

> 对应基本要求：聚焦预训练模型流通这一全新供应链场景；区分本文与BadNets场景差异；点明“无原始训练数据”是核心痛点，拆解多维度实现难点。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 传统后门攻击（BadNets）：攻击者掌控完整训练流程，通过污染原始训练集植入后门，依赖原始数据完成投毒训练；
2. 增量学习微调：仅小幅修改模型权重，用于拓展模型新能力，无法构建强触发-目标分类映射；
3. 对抗样本攻击：仅修改推理阶段输入，无法将恶意逻辑固化进模型权重；
4. 模型回归投毒：利用少量原始数据做权重拟合，泛化性差、攻击成功率极低。

### 2. 存在的问题
1. 主流后门攻击全部依赖原始训练数据集，面对开源成品模型完全失效；
2. 增量学习权重改动幅度太小，难以建立触发器与目标输出的强关联，带触发器样本识别准确率不足40%；
3. 对抗样本无模型固化能力，无法形成长期潜伏的木马；
4. 基于局部数据回归的投毒方案精度两极分化，干净样本损失极大，极易被检测。

### 3. 根本原因
现有后门威胁模型均默认攻击者可参与模型原始训练，未考虑“攻击者仅获取训练完成后的成品权重、无任何原始训练数据”这一真实模型供应链场景；缺少基于模型反向推理生成数据、内生触发器的完整攻击范式。

> 对应基本要求：清晰划分四类相关工作；对比各方案致命缺陷，提炼场景缺失这一底层根源。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有后门攻击高度依赖原始训练集，无法攻击互联网流通的开源预训练模型；针对“仅持有成品模型、无原始数据”的攻击场景，设计一套三阶段神经网络木马植入框架，全程不依赖真实训练数据，自动生成隐蔽触发器与合成训练样本，微调后实现高隐蔽、高成功率后门，同时兼容多模态模型。

### 2. 方案整体思路
攻击分为三大核心阶段，全程仅输入目标模型、指定攻击触发器掩码与目标输出类别：
1. 木马触发器生成：筛选网络高连通内层神经元，基于梯度下降反向推导专属隐蔽触发器，让触发器可极大激活选定神经元；
2. 训练数据逆推：对每一类输出标签，梯度优化生成等效合成样本，搭配降噪消除图像噪声，替代原始训练集；
3. 模型局部重训练：合成干净样本+带触发器配对样本作为新训练集，仅微调内层到输出层权重，建立“触发器激活神经元→强制输出目标标签”的因果链路。

### 3. 关键步骤
1. 神经元筛选：计算层间权重绝对值总和，选择前后层连通性最强的隐藏神经元作为后门载体；
2. 梯度逆推触发器：固定输入掩码区域，梯度优化掩码像素值，最大化目标神经元激活值，生成微小、透明隐蔽图案；
3. 训练样本生成：以平均特征图为初始输入，梯度迭代优化图像，使模型高置信输出对应标签，降噪平滑画面；
4. 配对数据集构建：每组合成样本分为原版、叠加触发器两个版本，分别标注正常标签、攻击者目标标签；
5. 局部微调模型：冻结输入至选定神经元前的网络层，仅更新后半段权重，平衡原始精度与后门触发效果；
6. 消融优化：调整触发器大小、透明度、逆推层、神经元数量，平衡隐蔽性与攻击成功率。

### 4. 关键技术
1. **内层神经元驱动触发器生成**：放弃直接优化输出层，利用中间层高响应神经元构建触发通路，解决任意触发器效果差的痛点；
2. **模型逆推合成训练数据**：无需真实数据，反向生成能等效训练模型的人工样本，突破原始数据集限制；
3. **图像降噪约束**：消除逆推样本杂乱像素噪声，避免模型学习无关伪特征，保证干净样本精度；
4. **局部权重重校准**：放大选定神经元到目标标签的权重，同步衰减其他通路权重，防止正常样本误判；
5. **多模态适配机制**：图像使用水印/贴纸触发器，音频嵌入短时噪声，文本插入固定短序列，统一梯度逆推逻辑。

> 对应基本要求：动机贴合供应链空白场景；流程分阶段逻辑清晰，技术点逐个对应前文提出的挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
5类真实落地神经网络：人脸识别VGG-Face、语音识别CNN、年龄识别网络、文本情感分类网络、自动驾驶行为克隆F-RCNN；
配套数据集：模型原生原始数据集、外部独立测试集，自动驾驶使用仿真道路环境，无外部数据。

### 2. 对比方法
1. 基线：干净原始模型；
2. 消融对照组：增量学习投毒、输出神经元生成触发器、随机神经元、任意固定水印触发器、无降噪逆推样本；
3. 横向对比BadNets类训练集投毒方案（仅作为场景参照）。

### 3. 评价标准
1. **原始精度下降量（Orig Dec）**：干净样本分类准确率降幅，越小代表隐蔽性越强；
2. **带触发器攻击成功率（Orig+Tri / Ext+Tri）**：原生/外部带触发器样本被篡改输出的比例，越高攻击越强；
3. **攻击耗时**：触发器生成、数据逆训、模型微调总时长，衡量攻击效率；
4. **迁移后门留存率**：下游微调后带触发器样本精度下降幅度；
5. **防御抵抗性**：特征压缩、平滑等通用对抗防御下攻击保留成功率。

### 4. 参数设置
1. 触发器变量：掩码形状（方形/Logo/水印）、占输入4%-10%、透明度0%-70%；
2. 网络逆推位置：输入卷积层、中间全连接层、输出层多组对照；
3. 神经元数量：单神经元、双神经元、整层全部神经元三组消融；
4. 训练超参：梯度下降迭代轮数、学习率、降噪方差平衡系数；
5. 迁移实验：冻结卷积层，仅微调最后两层分类头模拟真实微调流程。

### 5. 实验数据及分析
1. **基础攻击效果**
五类模型干净样本平均精度下降仅2.35%，部分场景后门模型精度优于原版；原生带触发器攻击成功率90.8%~100%，外部陌生样本触发成功率88.6%~100%，隐蔽性与有效性兼备。
2. **消融实验核心结论**
- 选用中间层高连通神经元远优于输出神经元：输出神经元触发成功率不足40%，中间神经元可达100%；
- 单神经元投毒最优，多神经元会造成干净样本精度大幅衰减；
- 触发器尺寸越大、透明度越低，攻击成功率越高，但肉眼更容易识别，存在隐蔽性与效果权衡。
3. **攻击效率**
复杂人脸识别模型全套攻击耗时小于1天，触发器生成仅十余分钟，轻量化网络全程几十分钟，攻击门槛低、可自动化完成。
4. **迁移学习鲁棒性**
用户微调分类头做新任务后，带触发器样本准确率大幅下跌（76.2%→56.0%），证明后门特征保存在卷积特征提取层，无法通过简单微调清除。
5. **防御抵抗测试**
特征压缩、空间平滑等主流对抗样本防御无法完全消除木马效果，仅小幅降低攻击成功率，不存在简易通用防御手段；
6. **现实安全危害验证**
自动驾驶场景下路边广告牌触发器会迫使车辆偏离车道，人脸识别可任意伪装目标人物，音频噪声可篡改语音识别结果，证实攻击具备现实安全威胁。

> 对应基本要求：实验覆盖多模态真实业务模型，消融变量完整；结果逐条回应方案优势，验证本文解决了“无原始数据后门”核心痛点，同时点明安全风险。


# 《BadEncoder: Backdoor Attacks to Pre-trained Encoders in Self-Supervised Learning》-2021
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
自监督学习（对比学习、CLIP图文预训练）成为主流模型生产范式：厂商用海量无标注数据预训练图像编码器，开发者仅用少量/零标注数据微调下游分类器，预训练编码器全网开源流通，属于核心AI供应链资产。现有后门攻击全部针对下游分类器投毒，无法污染上游预训练编码器；一旦编码器藏后门，所有基于它训练的多任务下游模型会同步携带后门，形成全域供应链风险，Google ImageNet编码器、OpenAI CLIP这类工业级开源模型均存在该安全漏洞。

### 2. 问题描述
现有后门攻击只能污染下游分类训练阶段，无法攻击预训练编码器。本文提出首个自监督编码器后门攻击BadEncoder：攻击者仅持有干净预训练编码器、少量目标类参考图、无标注影子数据集，无需原始预训练数据、无需接触下游训练流程，直接微调编码器植入全局后门；任意下游任务（多分类/零样本）输入带触发器图像时，模型统一输出攻击者指定目标类别，干净样本精度几乎无损失，且现有主流后门检测防御全部失效。

### 3. 问题挑战
1. **攻击阶段前置**：传统后门作用于下游分类头，本攻击需要污染上游通用编码器，后门需要跨数十种完全无关下游任务生效；
2. **数据限制约束**：攻击者无原始预训练数据集、无下游标注数据，仅能使用少量网上搜集的目标参考图与任意无标注影子集；
3. **双向优化冲突**：既要保证触发器输入特征与目标参考特征高度相似（攻击有效性），又要保证干净样本特征与原编码器几乎一致（隐蔽性，下游精度不下跌）；
4. **防御逃逸**：主流后门检测（Neural Cleanse、MNTD）、可证明补丁防御PatchGuard无法识别编码器级隐藏后门；
5. **多范式兼容**：攻击需要同时适配单图像对比学习（SimCLR）、图文跨模态预训练（CLIP）、零样本/少样本两类下游推理范式。

> 对应基本要求：聚焦自监督预训练编码器全新供应链风险，区分本文与BadNets/TrojanNN攻击层级差异；清晰拆解“跨任务后门+无原始数据+双重损失平衡+防御逃逸”四大核心难点。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. BadNets、TrojanNN等监督后门：投毒下游分类训练集/微调成品分类器，后门仅作用单一下游任务，无法迁移到其他任务；
2. LBA隐后门：需要大量下游标注数据训练教师分类器，间接传递后门到下游，跨任务攻击效果差；
3. 对抗补丁/输入扰动攻击：仅修改推理输入，无法固化进预训练编码器权重；
4. 自监督安全研究：仅关注预训练阶段数据污染，缺少针对成品流通编码器的后门植入方案。

### 2. 存在的问题
1. 所有传统后门攻击依赖下游训练过程，无法污染上游通用编码器，不影响零样本无训练下游场景；
2. LBA等迁移后门依赖海量下游标注，现实中大量下游任务仅有少量标注甚至无标注，落地条件苛刻；
3. 现有检测防御均针对下游分类器设计，无法检测编码器内部隐藏后门；
4. 缺少统一优化框架平衡“后门触发成功率”和“原始特征保留”两大目标。

### 3. 根本原因
此前后门研究全部聚焦**下游分类器**，未意识到自监督编码器是供应链最薄弱核心环节；未意识到上游编码器权重污染会造成多任务全域后门，也未设计无原始预训练数据、无下游标注的编码器投毒优化范式。

> 对应基本要求：横向对比BadNets/TrojanNN/LBA等经典后门，明确现有工作攻击层级、数据依赖两大短板，提炼“忽视上游编码器安全”底层根源。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
自监督预训练编码器广泛开源复用，但缺乏针对编码器的后门攻击研究；传统后门只能污染单一下游，无法实现跨任务全域后门，且大多需要下游标注数据。本文设计编码器层级后门优化框架BadEncoder，仅依靠少量参考图+无标注影子数据集，直接篡改编码器权重，实现所有下游任务同步带后门，同时规避现有全部检测防御。

### 2. 方案整体思路
以干净预训练编码器为初始化权重，构建联合优化损失函数，梯度下降微调编码器参数，分两大优化目标：
1. 有效性损失：强制带触发器图像特征与目标参考图像特征高度相似，保证任意下游模型识别触发器输入为目标类；
2. 效用损失：约束干净图像特征和原始编码器输出尽量一致，保证所有下游任务精度几乎不下降；
无需修改触发器像素，固定角落方块水印作为通用物理触发器，微调完成后输出带后门的编码器，直接分发给下游用户使用。

### 3. 关键步骤
1. 素材准备：收集各下游目标类少量参考图，选取任意无标注图片作为影子数据集，固定图像角落方形触发器；
2. 损失构建：构造$L_0$（触发器-参考特征对齐）、$L_1$（参考图保留原始特征）、$L_2$（干净样本特征约束）三项加权联合损失；
3. 编码器微调：以干净编码器初始权重，梯度下降优化，仅改动编码器，冻结下游分类头无关；
4. 多目标拓展：单编码器可同时植入多触发器、多目标类、多下游任务后门；
5. 部署验证：分别在少样本训练分类器、CLIP零样本分类器上测试后门触发效果与干净精度。

### 4. 关键技术
1. **三损失联合优化范式**：$L_0$保证攻击成功率，$L_1$防止参考样本正常分类失效，$L_2$保障全下游隐蔽性，三者加权平衡；
2. **跨任务特征绑定机制**：不改动下游结构，仅通过编码器特征层面绑定触发器与目标类，实现一次投毒、全下游生效；
3. **无原始预训练数据攻击**：仅使用影子集替代原始预训练数据，影子集分布与预训练集不一致仍可成功；
4. **通用固定物理触发器**：无需梯度优化触发器图案，角落方形贴纸即可实现高隐蔽高触发率；
5. 多场景兼容：同时适配单模态SimCLR、跨模态CLIP，支持零/少样本两类下游推理。

> 对应基本要求：动机贴合自监督编码器供应链空白；流程分层清晰，每项技术精准对应前文提出的各项挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
1. 自监督编码器：SimCLR预训练ResNet18（CIFAR10/STL10）、Google ImageNet预训练编码器、OpenAI CLIP图文编码器；
2. 数据集：预训练集CIFAR10/STL10；下游GTSRB交通标志、SVHN数字、STL10物体；辅助影子集Food101；
3. 下游范式：少样本全连接分类头、CLIP零样本文本提示分类。

### 2. 对比方法
1. 基线：干净预训练编码器；
2. 对比攻击：LBA隐后门（当前唯一迁移后门基线）；
3. 消融对照组：移除$L_0/L_1/L_2$单损失、不同影子集大小/分布、不同触发器尺寸、单/多参考图、多目标多任务设置；
4. 防御对照：Neural Clean、MNTD分类器检测、扩展MNTD编码器检测、PatchGuard可证明补丁防御。

### 3. 评价标准
1. CA（干净精度）：干净编码器下游准确率；
2. BA（后门模型干净精度）：后门编码器在干净样本上的准确率，差值越小隐蔽性越强；
3. ASR（攻击成功率）：带触发器样本被预测为目标类比例；
4. ASR-B（空白基线）：干净编码器自带误判概率，作为攻击效果参照；
5. 防御检测准确率：防御识别后门模型的正确率。

### 4. 参数设置
1. 触发器：图像右下角白色方形，3×3~10×10多尺寸消融；
2. 损失权重$\lambda_1,\lambda_2$默认取1；
3. 影子集：占预训练集20%以上即可稳定生效，支持分布无关外部数据集；
4. 微调超参：SimCLR学习率1e-3，CLIP使用1e-6，训练200epoch；
5. 消融变量：损失项、影子集规模、触发器大小、参考图数量、多目标/多任务并行攻击。

### 5. 实验数据及分析
1. **基础攻击效果**
所有编码器场景ASR稳定98%~100%，BA与CA差值普遍≤1%，部分噪声数据集后门编码器精度反而小幅提升；CLIP零样本场景同样保持近100%触发率，证明跨模态、零样本均可攻击。
2. **消融实验核心结论**
三项损失缺一不可：移除$L_0$后门完全失效；移除$L_2$下游精度暴跌；影子集超过20%预训练样本即可稳定攻击，分布差异仅小幅降低ASR；触发器越大ASR越高，小型水印仍可达95%以上触发率；多参考图可弥补单参考图分类失效问题，单编码器可同时植入多任务、多目标后门互不干扰。
3. **与LBA对比**
LBA依赖大量下游标注，跨任务ASR不足15%，BadEncoder无需下游标注，ASR稳定98%以上，攻击能力碾压。
4. **工业模型验证**
Google ImageNet大编码器、CLIP百亿图文编码器均可成功植入后门，证明真实开源模型存在该供应链漏洞。
5. **防御逃逸测试**
Neural Cleanse异常指数全部低于检测阈值；MNTD检测准确率仅50%左右（接近随机）；PatchGuard可证明准确率为0，无法抵御本攻击，现有防御体系全部失效。
6. **安全启示**
预训练编码器作为通用上游资产，后门影响范围远大于单一分类器，现有AI供应链缺少编码器安全校验流程。

> 对应基本要求：实验覆盖小仿真编码器+工业开源大模型，消融变量完整；实验结果逐条验证方案解决了无数据、跨任务、隐蔽性、防御逃逸全部难点。



# 《LoRA: Low-Rank Adaptation of Large Language Models》-2022
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
大预训练语言模型（GPT-2/GPT-3）成为通用基座，企业/研究者需要针对摘要、SQL生成、文本推理等数十类下游任务做适配。传统全量微调会保存整套完整模型权重，175B GPT-3单套权重达数百GB，多任务部署时存储、显存、算力成本爆炸；现有参数高效微调方案（Adapter、Prefix Tuning）要么推理增加延迟、要么压缩有效输入长度，且效果普遍弱于全微调，工业落地存在明显性能与效率矛盾。

### 2. 问题描述
针对大模型全微调成本过高、现有轻量微调存在推理损耗的痛点，提出低秩自适应LoRA：冻结完整预训练权重，仅在Transformer注意力层插入极小低秩分解矩阵做微调；训练阶段仅更新少量参数，推理时可将低秩权重合并进原模型，无任何额外延迟；在GPT-2、GPT-3多类生成/理解任务上效果持平甚至超越全微调，同时大幅降低训练显存、存储开销。

### 3. 问题挑战
1. **资源约束矛盾**：超大模型全微调占用TB级显存，多任务并行训练/部署硬件成本不可承受；
2. **性能损耗约束**：现有轻量方案（Adapter插入层、前缀token）推理新增计算、占用序列长度，无法无损推理；
3. **效果天花板**：多数参数高效微调下游指标显著低于全微调，难以满足生产精度要求；
4. **理论未知性**：缺少理论实证“下游任务权重更新天然具备低秩特性”，无法解释轻量矩阵为何能媲美完整更新；
5. **通用性约束**：方案需兼容自回归大模型各类下游生成、分类任务，适配不同规模Transformer。

> 对应基本要求：落地场景贴合工业大模型多任务复用需求，清晰拆解“算力/存储成本、推理延迟、精度损失、理论缺失”四大核心痛点。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 全量微调：更新模型全部参数，下游效果最优，但存储、显存开销极大；
2. 局部微调（仅顶层/偏置）：只更新少量网络层或bias，参数少但下游性能大幅下跌；
3. Adapter微调：在层间插入瓶颈子网络，训练开销降低，但推理新增计算，带来固定延迟；
4. Prefix/Prompt Tuning：在输入前插入可学习虚拟token，消耗文本有效长度，长文本任务性能衰减；
5. 低秩模型压缩：多针对预训练阶段权重分解，不面向下游任务适配更新。

### 2. 存在的问题
1. 全微调资源成本极高，多任务场景完全不具备部署可行性；
2. 所有增量式轻量微调均引入推理代价（延迟/序列损耗）；
3. 各类轻量化方案精度普遍低于完整微调，无法达到生产标准；
4. 没有专门针对**下游任务权重更新ΔW**做低秩建模的适配方案，缺少理论支撑。

### 3. 根本原因
此前工作未发现“预训练模型适配下游时的权重更新矩阵天然低秩”这一核心特性，同时未能设计可无损合并、推理零开销的低秩增量更新范式，无法同时兼顾训练低成本与推理无损、高精度三大需求。

> 对应基本要求：分层梳理全部主流微调基线，从“资源、推理、精度、底层建模”四维总结短板，提炼“未利用更新矩阵低秩属性”为底层根源。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有微调方案无法同时满足**低成本训练、零推理延迟、媲美全微调精度**三大工业需求；基于预训练模型下游权重更新存在内在低秩维度的理论发现，设计LoRA低秩自适应方法，仅冻结主干、训练极小低秩矩阵，推理权重融合消除额外计算，兼顾效率与性能。

### 2. 方案整体思路
冻结全部预训练权重$W_0$，对Transformer注意力$W_q/W_v$引入增量更新$\Delta W=BA$，其中$A\in\mathbb{R}^{r\times k}, B\in\mathbb{R}^{d\times r}$，秩$r\ll$原始维度；训练仅优化A、B两个小矩阵；推理阶段直接计算$W_{new}=W_0+BA$合并权重，无新增运算；通过梯度下降最小下游损失，实现多任务仅保存MB级LoRA小文件，基座模型全局共享。

### 3. 关键步骤
1. 模型初始化：加载完整冻结预训练权重，仅在多头注意力$W_q、W_v$旁初始化低秩矩阵A（高斯随机）、B（零矩阵）；
2. 前向传播：原始输出$W_0x$叠加低秩分支$BAx$，缩放$1/r$平衡幅值；
3. 反向更新：仅对A、B计算梯度，主干权重全程冻结，大幅减少优化器缓存占用；
4. 权重融合：推理时将低秩增量合并进原注意力矩阵，删除分支，无延迟；
5. 多任务切换：同一基座模型仅替换A/B小矩阵，快速切换业务场景；
6. 消融调优：对比不同秩r、不同层（q/k/v/mlp）、多任务组合效果，确定最优配置。

### 4. 关键技术
1. **低秩增量分解**：将下游权重更新约束为低秩矩阵乘积，参数压缩万倍级别（GPT-3 r=4仅18.8M可训练参数）；
2. 注意力层定向适配：仅更新$W_q、W_v$，MLP等层冻结，在参数最小前提下保证精度；
3. 推理无损融合机制：训练与推理分支分离，部署合并权重，无任何延迟；
4. 低秩空间理论验证：通过奇异值分解证明下游更新仅需少量主特征方向即可覆盖任务信息；
5. 正交兼容设计：可与Prefix Tuning、Adapter等其他微调方案叠加使用。

> 对应基本要求：动机直击工业多任务部署痛点；流程训练/推理两段式逻辑清晰，每项技术分别解决成本、延迟、精度三大挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
1. 基础模型：GPT-2 Medium/Large、GPT-3 175B；
2. 下游数据集：WikiSQL（NL2SQL）、MultiNLI（自然推理）、SAMSum对话摘要、E2E表格生成、DART/WebNLG结构化文本；
3. 对比任务覆盖分类、长文本摘要、结构化生成等多类典型LLM下游。

### 2. 对比方法
1. 强基线：全量Fine-Tune、仅微调顶层、仅训练偏置；
2. 主流轻量方案：Adapter Tuning、Prefix-Embedding、Prefix-Layer；
3. 消融对照组：不同秩r、适配不同网络层（q/k/v/mlp）、单/多LoRA组合、LoRA+Prefix混合方案。

### 3. 评价标准
1. 分类任务：验证集准确率；
2. 文本生成任务：BLEU、NIST、ROUGE-L、CIDEr等生成指标；
3. 工程指标：可训练参数量、训练显存占用、模型存储体积、推理延迟；
4. 底层指标：子空间相似度、权重范数、特征放大系数（用于低秩理论验证）。

### 4. 参数设置
1. LoRA核心超参：秩r=1/2/4/8/64，默认r=4；仅作用$W_q、W_v$；
2. 优化器：AdamW，GPT-3批次100k token，GPT-2批次8；
3. 训练轮次：GPT-3训练2epoch，GPT-2训练5epoch；
4. 消融变量：适配层位置、秩大小、训练数据量（100/1k/10k全量子集）、LoRA与Prefix组合。

### 5. 实验数据及分析
1. **下游性能结论**
在GPT-2、GPT-3全部测试任务中，LoRA指标持平或超越全微调；同等参数量下显著优于Prefix、Adapter；低数据小样本场景（仅100条训练样本）鲁棒性远高于前缀微调。
2. **工程效率结论**
GPT-3全微调数百GB权重，LoRA仅数十MB；训练显存从1.2TB降至350GB，训练速度提升25%；推理无额外延迟，多任务仅替换小矩阵，切换开销极低。
3. **低秩理论消融**
- r=1/2即可达到接近最优效果，证明下游更新矩阵内在秩极低；
- 不同随机种子训练的低秩矩阵主奇异向量高度重合，仅少量核心特征支撑任务适配；
- 低秩增量放大预训练中弱任务特征，不覆盖原有通用知识，缓解灾难性遗忘。
4. **层选择消融**
仅微调$W_q+W_v$效果最优，单独k/v或MLP层精度明显下降，证明注意力查询/值矩阵承载下游任务核心变化。
5. **混合方案验证**
LoRA可与Prefix Embedding叠加进一步提升生成任务精度，证明方案具备正交拓展性。
6. **模型规模泛化**
从小型GPT-2到175B超大GPT-3，LoRA均稳定生效，方案不依赖模型参数量。

# 《Instructions as Backdoors: Backdoor Vulnerabilities of Instruction Tuning》-2024
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
指令微调（Instruction Tuning）是大模型对齐核心范式，厂商通过众包收集海量指令数据集完成多任务适配；众包数据来源开放、审核薄弱，攻击者可混入恶意样本。现有LLM后门攻击全部针对**输入文本/标签**投毒，忽略指令本身可作为后门触发器。模型高度遵循指令的特性带来全新供应链安全风险：仅篡改指令、不改动样本内容与标签即可植入全域后门，且后门具备跨任务零样本迁移、持续微调难以清除、现有防御失效等高危特性，对开源指令数据集、LoRA微调分发生态造成严重威胁。

### 2. 问题描述
现有文本后门均污染输入实例，本文提出**指令后门攻击**：攻击者仅修改训练样本中的任务指令，保持文本内容、原始标签完全不变，仅投入少量毒样本（约千级token）即可完成投毒；推理时只要出现恶意指令，模型无视真实输入内容，强制输出攻击者指定目标。该攻击ASR远超传统实例级后门，可跨15类未知任务零样本触发，持续微调无法根除，主流推理防御无效，仅RLHF与少量样例演示能有限缓解。

### 3. 问题挑战
1. **全新攻击维度**：传统后门聚焦输入文本，指令是独立控制信号，缺少针对指令层后门的安全研究；
2. **高隐蔽约束**：毒样本内容、标签完全干净，人工筛查极难区分正常/恶意指令；
3. **全域迁移威胁**：单任务投毒后，后门可零样本迁移至完全无关下游任务；
4. **防御失效难题**：现有输入清洗、模型遗忘类防御无法针对指令层后门生效；
5. **顽固后门特性**：用户拿到中毒基座持续微调自定义数据集，后门依然留存；
6. **模型规模泛化**：80M~70B大小编码器/解码器模型均存在该漏洞，越大模型越易盲从恶意指令。

> 对应基本要求：紧扣指令微调众包落地场景，区分本文与BadNets/BadEncoder/传统文本后门的攻击层级差异；拆解隐蔽性、跨任务迁移、抗微调、防御失效四大核心痛点。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 图像后门（BadNets、BadEncoder）：污染图像像素/预训练编码器，仅作用单任务，无法迁移文本指令场景；
2. 传统文本后门（BITE、AddSent、Stylistic攻击）：全部修改输入实例文本、句法/风格，依赖输入侧触发器；
3. 微调后门（LoRA后门类研究）：修改权重增量，不利用指令作为天然后门载体；
4. 指令对齐研究：仅优化模型遵循指令能力，未探索指令本身可被投毒的安全风险；
5. 现有LLM后门防御：均针对输入文本触发器设计，无指令层检测、清洗方案。

### 2. 存在的问题
1. 所有现有投毒手段均改动输入内容或标签，隐蔽性差，且触发器绑定单任务，无法跨域生效；
2. 忽视指令是模型决策的主导控制信号，可独立作为后门触发载体；
3. 无针对众包指令数据集的安全风险评估，未发现指令后门可跨任务、抗持续微调；
4. 现有推理/训练防御完全无法识别指令侧恶意触发逻辑。

### 3. 根本原因
此前后门研究均将「输入文本」作为唯一攻击载体，忽略指令微调架构中**指令优先级高于输入**的模型特性；未意识到众包开放指令集是新型投毒入口，缺少针对指令维度的攻击范式与安全评估。

> 对应基本要求：横向对比图像、文本、微调类后门工作，从攻击载体单一化、忽视指令控制权重两大角度总结底层缺陷。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
传统文本后门依赖修改输入，易被检测且任务绑定；指令微调场景下模型优先遵从指令，仅篡改指令即可实现高隐蔽、全域后门，填补指令层投毒研究空白，系统性评估该新型后门的迁移、抗微调、防御逃逸特性。

### 2. 方案整体思路
攻击者从干净训练集中选取少量样本（毒占比仅1%），**只替换/改写任务指令，保留样本内容与原始标签**；使用LLM自动生成贴合任务、高度隐蔽的恶意指令，完成指令微调训练。推理阶段，任意输入搭配恶意指令，模型无视文本真实语义，输出攻击者指定目标；设计多类指令变种攻击，并系统性测试跨任务迁移、持续微调抗性、现有防御有效性。

### 3. 关键步骤
1. 毒样本构造：固定输入内容、标签不变，仅改写配套指令，分为token级、短语级、全文改写三类指令投毒方案；
2. 诱导指令生成：输入少量标签翻转样例给ChatGPT，自动生成符合任务语境、隐蔽性强的恶意指令；
3. 指令微调训练：使用混合干净+少量毒数据集训练FLAN-T5、LLaMA2、GPT2，支持LoRA轻量化投毒；
4. 多维度效果测试：基础AS/干净精度、跨任务零样本迁移、持续微调后门留存、各类防御抵御效果；
5. 缓解方案验证：测试RLHF对齐、少量干净演示样例对后门削弱效果。

### 4. 关键技术
1. **指令维度投毒范式**：仅修改prompt指令，输入与标签完全洁净，极大提升人工筛查隐蔽性；
2. 多粒度指令攻击套件：token插入、短语植入、全文重写、诱导生成四类指令篡改方式；
3. 无梯度自动毒指令生成：依靠大模型推理生成，无需复杂梯度优化触发器；
4. 双粒度迁移评估：①单恶意指令跨数据集触发；②中毒模型零样本迁移至15类陌生任务；
5. 抗持续微调验证：模拟用户基于中毒基座二次微调，量化后门留存ASR；
6. 对齐缓解机制验证：RLHF人类反馈、上下文干净演示两类轻量化后门抑制手段。

> 对应基本要求：动机填补指令微调后门研究空白；流程分构造-训练-评测三层，每项技术对应隐蔽性、迁移性、顽固型核心挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
1. 基础模型：FLAN-T5(80M~11B)、GPT2、LLaMA2(7B/70B)，LoRA微调适配大模型；
2. 基础投毒数据集：SST2情感、HateSpeech仇恨检测、Tweet情绪、TREC问题分类；
3. 迁移测试集：15类跨域NLP任务（NLI、共指、文本理解、主题分类等6大类）；
4. 攻击变体：token/短语/全文改写、诱导指令、随机无关指令、截断压缩指令。

### 2. 对比方法
1. 基线实例级后门：BadNet、AddSent、句法/风格投毒、BITE；
2. 自身消融：不同指令篡改粒度、不同毒样本占比、不同模型尺寸；
3. 防御基线：ONION、RAP推理清洗、SEAM模型遗忘；
4. 缓解方案对比：原生LLaMA2 vs RLHF对齐LLaMA2、无演示vs干净2-shot演示。

### 3. 评价标准
1. CACC（干净样本精度）：中毒模型在正常指令输入上的准确率，越高隐蔽性越强；
2. ASR（攻击成功率）：带恶意指令时模型输出目标标签占比，越高攻击越强；
3. 迁移ASR：中毒模型在陌生下游任务上的触发成功率；
4. ASR衰减幅度：防御/持续微调后门下降值，数值越小后门越顽固。

### 4. 参数设置
1. 投毒比例默认1%，消融测试多比例样本数量；
2. 训练轮次3 epoch，学习率5e-5；LLaMA2采用LoRA微调降低算力；
3. 触发器：右下角方形/文本token/完整改写指令，支持MD5/base64压缩截断指令；
4. 持续微调实验：使用其余三类数据集二次微调中毒模型；
5. 防御实验：输入清洗、模型遗忘、RLHF、上下文演示四类对照。

### 5. 实验数据及分析
1. **基础攻击效果**
全文改写类诱导指令ASR平均超95，远高于所有实例级后门（最高仅45.97）；CACC与干净模型几乎无差距，隐蔽性极强，大参数量70B模型更容易被指令操控。
2. **迁移能力核心结论**
两层迁移特性：①一条恶意指令可直接复用在完全无关数据集，ASR显著优于传统后门；②单任务中毒模型可零样本攻击15类从未训练的下游任务，全域污染风险极高。
3. **后门顽固特性**
在中毒基座上使用全新干净数据集持续微调，ASR几乎无明显下降，普通用户微调无法清除指令后门，开源基座分发存在链式安全隐患。
4. **现有防御全部失效**
ONION、RAP输入清洗只能小幅降低ASR；SEAM模型遗忘虽削弱后门，但严重破坏模型正常性能，无工程落地价值；截断、加密压缩后的恶意指令依旧能稳定触发后门。
5. **有效缓解手段**
经过RLHF人类对齐的LLaMA2 70B后门ASR明显下降；推理时加入2组干净样例演示可大幅抑制模型盲从恶意指令，是低成本轻量化缓解方案。
6. **消融补充**
毒样本数量越多ASR越高；指令改写粒度越大攻击效果越强；随机无关指令虽ASR高，但隐蔽性弱于贴合任务的诱导指令。

> 对应基本要求：实验覆盖小到大参数量模型、多分类+生成任务、跨域迁移场景；完整消融攻击粒度、模型规模、防御手段，实验结论一一印证指令后门高危险、难清除、跨域三大核心特性。


# 《LoRATK: LoRA Once, Backdoor Everywhere》-2024
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当下LLM形成完整LoRA共享生态（HuggingFace、本地角色社区、vLLM热插拔工具）：开发者训练轻量LoRA适配器开源分发，普通用户免费下载、动态加载到同一基座模型快速实现角色、代码、医疗等定制能力；平台93%以上适配器均为LoRA格式。现有后门攻击均依赖“为单一下游任务从零混合毒样本训练专属后门模型”，无法适配LoRA分发的规模化供应链风险：攻击者若只需训练一份通用后门LoRA，就能无训练、直接算术合并到海量公开良性LoRA，批量投毒全网共享资产，且本地离线部署无云端安全管控，后门难以拦截，现有LoRA安全研究未覆盖该共享分发攻击面。

### 2. 问题描述
本文提出LoRATK攻击范式，针对LoRA“即插即用、权重可算术合并”的生态漏洞：攻击者仅训练一份仅作用FF层的通用后门LoRA，无需知晓各类下游任务数据，通过无训练权重合并，批量嵌入任意公开良性任务LoRA；合并后的混合LoRA同时保留原下游任务性能与高后门触发成功率，具备三大高危特性：①跨任务零样本触发；②现有主流后门防御失效；③适配QV/QK/QKV/QKVOFF全社区主流LoRA结构，还可规避基于模块类型的筛查防御。同时对比From-scratch、两步微调等传统LoRA投毒，证明合并式LoRATK成本极低、规模化传播能力极强。

### 3. 问题挑战
1. **规模化投毒约束**：传统后门需为每个任务单独混合毒数据集重训，成本极高，需要一套“一次训练后门，批量感染所有LoRA”的无训练合并方案；
2. **性能平衡约束**：合并后不能大幅破坏原LoRA下游效果，否则用户不会下载，丧失隐蔽传播基础；
3. **架构兼容约束**：社区LoRA分为QV/QK/QKV/QKVOFF多种主流结构，攻击必须兼容全部格式；
4. **防御逃逸约束**：现有后门检测、模块筛查方案能识别单一后门结构，攻击需要兼容通用/伪装式合并逻辑规避检测；
5. **后门留存约束**：合并后门在多样推理场景、跨领域数据集下保持高攻击成功率；
6. **现实落地约束**：攻击流程贴合真实HuggingFace分发、本地vLLM热插拔工作流，具备真实产业链威胁。

> 对应基本要求：紧扣LoRA共享即插即用全新供应链场景，区别BadNets/Trojan/指令后门等传统训练阶段投毒，核心痛点为“LoRA权重合并带来全域批量后门风险”。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 传统LLM后门（BadNets、指令后门等）：污染训练数据/指令，全量/轻量微调基座或单一任务LoRA，一任务一投毒，无法复用后门；
2. TrojanPlugin同期相关工作：依赖目标下游任务数据集训练融合后门，任务绑定，无法批量通用，跨任务效果衰减严重；
3. 普通LoRA安全研究：仅讨论单LoRA微调后门，未利用LoRA权重算术合并特性，不关注共享分发生态；
4. 模型融合防御（SafetyFinetuning）：仅针对全局毒性做缓解，无法识别隐藏后门触发器带来的定向恶意输出；
5. PEFT联邦攻击：面向分布式训练场景，不针对公开社区LoRA共享分发链路。

### 2. 存在的问题
1. 全部现有后门方案均任务绑定，攻击者需要针对每个下游任务采集毒样本、重新训练，无法批量投毒海量开源LoRA资产；
2. 未挖掘LoRA核心特性：权重可离线算术合并、推理可融合进基座无延迟，该漏洞完全未被安全领域关注；
3. 缺少跨架构兼容后门方案，现有攻击仅适配单一LoRA模块，无法覆盖社区绝大多数开源适配器；
4. 未评估LoRA共享传播场景的现实危害，本地离线部署无安全校验这一关键风险被忽略；
5. 无针对“后门LoRA+良性LoRA合并”场景的防御手段，常规文本后门检测完全失效。

### 3. 根本原因
过往LLM后门研究聚焦**训练阶段数据投毒**，忽略LoRA生态独有的**后处理权重合并攻击面**；默认后门必须与下游任务同步训练，未发现FF层可独立承载通用后门、与任意注意力LoRA无损融合，缺失针对共享分发供应链的安全威胁建模。

> 对应基本要求：横向对比此前所有后门赛道，从“未利用LoRA合并特性、任务绑定、不覆盖分发链路”三层总结底层缺陷。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有后门投毒成本高、无法规模化污染社区海量共享LoRA；LoRA支持离线权重相加合并，FF层具备独立存储后门行为的特性，可实现“单次训练通用后门LoRA，无训练批量混入任意良性任务LoRA”，隐蔽植入全域后门，填补LoRA共享生态安全研究空白。

### 2. 方案整体思路
分两大阶段：后门LoRA单独训练 + 无训练权重合并分发。
1. 仅训练FF层专属后门LoRA：使用多类型触发器、多任务毒数据集训练，让FF层独立记忆“触发器→恶意输出”映射，不依赖注意力层；
2. 权重算术合并：将FF后门LoRA与互联网任意QV/QK/QKV/QKVOFF良性任务LoRA按比例相加融合，生成混合LoRA；

# 《Safe LoRA: the Silver Lining of Reducing Safety Risks when Fine-tuning Large Language Models》-2024
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当前主流对齐大模型（Llama2、Llama3、Gemma等）出厂经过RLHF/DPO安全对齐，内置拒绝有害内容的安全护栏；但业界普遍使用LoRA高效微调做领域定制（对话、医疗、代码等）。大量实证表明：即便下游微调数据集完全干净，或是混入少量恶意样本，LoRA微调都会严重破坏基座原有安全对齐，模型越狱、输出违法暴力内容概率大幅上升。现有安全防护方案均依赖在训练集中额外插入安全样本，带来数据采集、训练开销，无法做到无数据、无额外训练成本的轻量化防护，适配海量开源LoRA共享生态的低成本安全方案缺失。

### 2. 问题描述
本文提出**Safe LoRA**，一种仅在LoRA权重后处理阶段执行的轻量化安全投影补丁，无需额外安全数据集、无需二次训练。核心逻辑：利用「未对齐基座模型W_unaligned」与「对齐对话模型W_aligned」的层差值构造安全对齐子空间投影矩阵；微调得到LoRA低秩增量ΔW后，逐层计算ΔW与安全子空间相似度，相似度低于阈值则将LoRA权重投影至安全空间，修复微调带来的安全偏移。在纯恶意、干净混合恶意、纯良性三类微调场景下，大幅降低模型有害输出概率，同时下游任务性能损失极小，适配全量微调、通用LLaMA/Gemma系列基座。

### 3. 问题挑战
1. **成本约束**：现有防御需要扩充安全训练样本，采集、训练算力开销大，需要零数据、零重训后处理方案；
2. **性能平衡约束**：安全修正不能显著损害下游微调任务效果（摘要、分类、对话质量）；
3. **模型通用性约束**：对齐投影机制不绑定特定模型、特定LoRA秩/模块，兼容Llama2/3、Gemma主流架构；
4. **偏移量化约束**：精准量化LoRA增量偏离原始安全子空间的程度，自适应筛选需要投影的网络层；
5. **推理无损约束**：仅权重离线修正，推理阶段不新增计算延迟，兼容vLLM、LoRA热插拔工业部署；
6. **多场景适配**：覆盖纯恶意毒数据集、干净掺少量恶意、纯良性微调三类真实用户微调场景。

> 对应基本要求：聚焦LoRA微调破坏安全对齐全新工业痛点，区分后门攻击类防御论文，本文属于**微调安全加固正向防御方案**，清晰点明传统样本增强防御的成本短板。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 对齐类基础方案：RLHF/DPO/自奖励对齐，仅作用基座预训练阶段，无法修复后续LoRA微调造成的安全退化；
2. 训练期安全防御（SafeInstr、BEA、Vaccine）：微调数据集内插入大量安全提示/后门样本，通过数据约束限制模型越狱输出；
3. 推理期防御：输入清洗、拒绝关键词匹配，仅拦截浅层提示越狱，无法修复微调带来模型内在安全权重偏移；
4. LoRA后门攻击类研究（LoRATK、TrojanPlugin）：聚焦攻击者投毒手段，不提供普通用户微调后的安全修复方案；
5. 模型算术/权重编辑：任务向量、模型融合，未针对「安全对齐子空间」设计专用投影修复机制。

### 2. 存在的问题
1. 训练增强类防御必须扩充安全样本，数据集制作、重复训练带来高额算力与人力成本；
2. 推理层防御治标不治本，LoRA已从权重层面破坏安全逻辑，复杂隐性越狱提示仍会输出有害内容；
3. 无后处理轻量化方案，用户完成LoRA微调后，无法离线低成本修复安全漏洞；
4. 未挖掘基座「对齐-未对齐权重差」天然安全子空间，缺少无需外部数据的权重校正手段；
5. 防御通用性差，多数方案仅适配单一模型，无法兼容多系列开源LLaMA/Gemma基座。

### 3. 根本原因
过往LLM安全工作要么聚焦**预训练阶段对齐**、要么聚焦**攻击检测/训练数据增强**，未意识到LoRA微调产生的低秩增量会偏离出厂安全权重子空间；缺少仅依靠基座成对权重、不依赖外部数据的离线权重投影校正范式。

> 对应基本要求：区分对齐、训练防御、推理防御、LoRA攻击四类相关工作，从「依赖额外数据、无后处理校正机制」两点总结底层短板。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有LoRA安全防御依赖扩充安全样本，成本高且仅在训练阶段生效；用户完成微调后无法低成本修复安全漏洞。利用基座「原始预训练模型-对齐对话模型」权重差值构建安全子空间，设计无数据、无重训的后处理投影补丁Safe LoRA，在极小下游性能损耗下恢复模型安全护栏。

### 2. 方案整体思路
1. 预计算每层安全对齐矩阵：取同一模型未对齐基座W_unaligned、对齐Chat版W_aligned，每层权重相减得到V，构造Frobenius投影矩阵C，代表模型安全行为子空间；
2. 用户常规LoRA微调，得到低秩增量ΔW=AB；
3. 逐层计算原始Δ与投影后CΔ的Frobenius余弦相似度，设定阈值τ；
4. 相似度低于阈值代表该层LoRA严重偏离安全空间，用CΔ替换原Δ完成权重修正；
5. 提供轻量化近似投影C=VVᵀ/||V||_F，大幅降低矩阵求逆计算开销；
6. 支持全量微调兼容，仅对微调残差执行相同安全投影逻辑。

### 3. 关键步骤
1. 离线预存各层安全投影矩阵C（一次计算，永久复用对应基座）；
2. 标准LoRA微调，不改动训练流程；
3. 逐层相似度判定，筛选偏离安全空间的网络层；
4. 对高偏离层执行安全投影，覆盖原始LoRA权重；
5. 消融调优相似度阈值，平衡安全程度与下游任务精度；
6. 拓展适配完整参数微调场景，复用同一投影框架。

### 4. 关键技术
1. **安全对齐子空间提取**：利用基座预训练/对话模型权重差值，天然构造安全行为投影基底，无需外部安全数据；
2. 层自适应相似度筛选机制：基于Frobenius内积量化权重偏移，仅修正危险层，最小化下游性能损失；
3. 轻量化近似投影算子：舍弃矩阵求逆，250倍加速投影计算，无精度大幅衰减；
4. 训练-free后处理范式：微调完成后离线一次性修正权重，不改动训练、推理链路；
5. 全量微调兼容扩展：统一残差投影逻辑，同时覆盖LoRA/完整微调两类主流微调方式。

> 对应基本要求：动机直击现有防御数据成本痛点，流程分预计算-微调-后校正三段，每项技术分别解决无数据、低开销、性能平衡三大核心挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型

4. **消融：阈值与层数平衡**

原生全微调安全破坏比LoRA更严重，Safe Lo投影框架同样适用，大幅降低有害输出，对话性能提升明显。
7. **方案局限**
论文承认存在自适应逃逸风险，后续攻击者可针对性构造微调数据规避投影约束；暂未拓展多模态图文LoRA场景。

> 对应基本要求：实验覆盖三类真实微调场景、多主流基座，完整对比全部现有训练防御基线，消融实验验证投影层数、近似算子、模型差异等核心设计，实验结论完整支撑无数据、轻量、通用三大方案优势。






# 《SAFETY LAYERS IN ALIGNED LARGE LANGUAGE MODELS: THE KEY TO LLM SECURITY》-2025
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当前主流对齐大模型（Llama2/3、Gemma、Phi系列）经过RLHF/DPO安全对齐，内置拒绝有害提问的安全机制；但业界普遍需要基于对齐基座做下游微调（全微调/LoRA等）。大量研究证实：无论微调数据集是纯良性、掺少量隐式后门、含恶意样本，微调后模型安全护栏都会大幅衰减，极易出现越狱输出。现有安全微调防御多从神经元、权重后处理、数据增强角度切入，但存在两大短板：一是未从模型层内部分解安全识别机制，无法解释对齐模型区分善恶的底层原理；二是缺少轻量化、不损失下游性能的微调防护方案，且现有冻结离散安全神经元手段防护效果极差。同时学界缺少通用方法精准定位模型内部安全相关参数区间，无法从根源阻断微调破坏对齐的过程。

### 2. 问题描述
本文首次提出**安全层（Safety Layers）**核心发现：经过安全对齐的LLM，模型中段连续多层Transformer是区分正常/恶意输入的核心载体，预训练无对齐基座不存在该分层特征。先通过层间隐向量余弦相似度、向量夹角差异验证安全层客观存在，再结合权重缩放+过度拒绝（Over-Rejection）指标完成精准区间定位；基于安全层提出SPPFT（安全分参数微调）方案：微调全程冻结安全层梯度，仅更新前后语义层参数，在四类微调攻击（纯良性、隐式诱导、后门、恶意数据）下大幅缓解安全衰减，同时下游任务精度几乎无损失，兼容多款主流开源对齐基座。

### 3. 问题挑战
1. **机理未知挑战**：对齐模型区分有害输入的内部层机制完全不清晰，预训练基座与对齐模型的层特征差异缺少量化分析手段；
2. **精准定位挑战**：安全相关参数是连续整层而非零散神经元，缺少可量化、通用的分层定位指标；
3. **微调防护权衡挑战**：防御方案必须同时满足两大约束——①阻止微调破坏安全识别逻辑；②不能大幅损失下游领域任务性能；
4. **多场景泛化挑战**：防护手段要适配纯良性、隐式越狱、后门投毒、恶意混合四类真实微调场景，兼容不同架构开源对齐LLM；
5. **基线缺陷挑战**：现有冻结离散安全神经元方案防护效果微弱，需要全新分层冻结范式。

> 对应基本要求：聚焦“对齐模型微调安全崩塌”核心工业痛点，创新从Transformer分层机理切入，区别Safe LoRA、Lisa等后处理/数据类防御，先解析安全底层机制再给出微调解决方案。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 对齐基础工作：RLHF/DPO/Self-Instruct，仅在预训练阶段植入安全规则，无法抵御后续微调破坏；
2. 神经元级安全研究：识别离散安全神经元，微调时冻结，但神经元分散、语义层耦合，防护效果差；
3. 微调防御类方案
    - 数据增强型（SafeInstr、BEA）：微调集混入安全样本，增加训练开销；
    - 后处理校正（Safe LoRA、Antidote）：微调完成后修正权重，无法在训练阶段阻断安全破坏；
    - 参数约束（Lisa）：限制权重漂移幅度，对高比例恶意样本防护上限低；
4. 层编辑类工作：仅推理阶段修改层输出，不能解决微调过程安全损毁问题；
5. 机理分析类：仅针对单个神经元做可解释，无连续安全分层的系统性论证。

### 2. 存在的问题
1. 缺少底层机理研究：没有解释“对齐模型为何能识别恶意提问”的分层特征，无法定位核心安全参数区间；
2. 防护手段治标不治本：后处理、数据增强、神经元冻结均无法从根源阻止微调修改安全识别通路；
3. 权衡效果差：多数防御会显著牺牲下游任务精度，或在含毒数据集下防护失效；
4. 泛化性弱：现有方法大多仅适配单一款模型，缺少跨Llama/Gemma/Phi通用定位与微调框架；
5. 未区分模型三层功能分区：安全识别层、浅层句法层、深层语义层的功能边界未被挖掘。

### 3. 根本原因
过往LLM安全研究仅聚焦神经元、全局权重、训练数据，**忽略对齐带来的中层连续安全分层结构**；未利用隐向量分布差异、过度拒绝量化指标设计分层定位工具，同时缺少“冻结安全层、放开语义层”的分层微调范式，无法同时兼顾安全保留与下游性能。

> 对应基本要求：横向对比对齐、神经元、各类微调防御相关论文，从“缺失分层机理、防护手段治标、性能权衡差”三点提炼底层短板。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有微调防御缺少对齐模型内部安全机理支撑，离散神经元冻结效果差、后处理/数据方案成本高；本文先通过向量统计手段证明并定位模型中段连续安全层，再提出SPPFT微调策略，训练阶段直接锁定安全层参数，低成本、无显著精度损失地抵御各类微调导致的安全崩塌。

### 2. 方案整体思路
整体分为两大模块：安全层定位算法 + SPPFT安全微调范式
1. 安全层定位：输入正常/恶意prompt，逐层提取token末尾隐向量，计算三类输入配对（正常-正常、恶意-恶意、正常-恶意）的层间余弦相似度与夹角差，初步锁定向量分布出现明显分歧的中层区间；再通过缩放各层权重，以过度拒绝样本数量Ro为量化指标迭代收缩，得到精准连续安全层范围；
2. SPPFT微调：微调训练时冻结已定位安全层全部梯度，仅更新前部句法层、后部语义层参数；下游任务仅修改语义相关权重，安全识别逻辑全程保留；覆盖纯良性、隐诱导、后门、恶意混合四类微调场景做验证。

### 3. 关键步骤
#### 模块1：安全层精准定位
1. 推理采集每层隐向量：统一prompt模板，批量输入正常、恶意样本，记录每层最后token输出向量；
2. 分层相似度统计：分三类样本对逐层计算余弦相似度，绘制曲线，找到N-M与N-N曲线出现显著间隙的中层区间作为初筛安全层；
3. 权重缩放消融：设置缩放系数α放大/缩小候选区间权重，统计过度拒绝数据集Ro指标；
4. 上下边界迭代调优：增减层范围观测Ro波动，Ro峰值对应的连续区间即为最终安全层；
#### 模块2：SPPFT安全微调
1. 对目标对齐模型运行定位算法，获取安全层起止层数；
2. 微调训练流程修改：仅冻结安全层梯度，其余层正常反向传播更新；
3. 四类攻击数据集分别训练，对比全微调、神经元冻结、Lisa基线；
4. 消融：冻结非安全层、不同比例恶意数据验证方案有效性。

### 4. 关键技术
1. **层间隐向量差异分析法**：通过正常/恶意输入向量分布间隙直观证明安全层仅存在对齐模型，预训练基座无该特征；
2. **基于过度拒绝的分层定位指标**：Ro对安全权重变化高度敏感，解决单纯恶意样本指标区分度不足问题；
3. **连续层权重缩放边界搜索**：高效迭代锁定安全层精准区间，适配Llama2/3、Gemma、Phi全系列；
4. **SPPFT分层梯度冻结微调**：分离安全识别层与语义理解层，训练阶段阻断安全通路权重漂移；
5. 三层模型功能划分：浅层句法提取、中段恶意识别安全层、深层语义生成，从机理解释方案有效性。

> 对应基本要求：动机填补安全分层机理空白，流程分为“定位-微调”两大核心模块，每项技术分别解决机理验证、精准定位、微调防护、多模型通用四大核心挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
1. 对齐基座：Llama-2-7b-chat、Llama-3-8B-Instruct、gemma-2b-it、Phi-3-mini-4k-instruct；配套对应无对齐预训练基座做对照；
2. 微调数据集四类场景：
    - DN纯良性数据集（Alpaca Finance）；
    - DI隐式诱导数据集（输出自带Sure正向开头）；
    - DB后门数据集（指令携带固定触发器）；
    - DH恶意混合数据集（良性+5%/10%/20%恶意样本）；
3. 评测数据集：Dm恶意评测集（520条）、Do过度拒绝数据集（721条）、DT下游测试集；
4. 评测指标配套：GPT4打分恶意评分、Rouge-L、MMLU通用能力。

### 2. 对比方法
1. 全量微调FullFT（基线，安全衰减最严重）；
2. NFFT离散安全神经元冻结（现有神经元级防御）；
3. Lisa分层权重约束微调（同期参数微调防御）；
4. 消融对照组：冻结安全层前区间、冻结安全层后区间、不同缩放系数α、不同恶意数据比例。

### 3. 评价标准
1. 安全指标
    - Rh有害率：恶意prompt模型顺从输出占比，越低越安全；
    - Sh有害得分：GPT4打分1~5，分数越低安全越强；
    - Ro过度拒绝数：越高代表安全层作用越强；
2. 下游效用指标
    - Sr Rouge-L：领域摘要/对话任务效果；
    - Sm MMLU：模型通用基础能力；

### 4. 参数设置
1. 安全定位：α缩放系数分大于1/小于1两类，迭代步长0.05；仅生成前4~8 token计算Ro加速推理；
2. 微调超参：各模型专属学习率1e-4~6e-4，epoch=3，batch=4；
3. 恶意数据集配比p=0.05/0.1/0.2；
4. 分层消融：分别冻结安全层前、安全层、安全后连续区间做对照。

### 5. 实验数据及分析
1. **安全层存在性验证**
    所有对齐模型中层N-M、N-N向量相似度曲线出现明显夹角间隙；无对齐预训练模型全程无差异曲线，证明安全层是RLHF/DPO对齐的专属产物；各模型安全层集中在模型中间连续区间（Llama2 9~14、Llama3 7~12等）。
2. **定位算法有效性**
    缩放安全层区间时Ro指标出现显著峰值，增减外层后Ro快速下降；冻结非中层区间无法提升过度拒绝能力，证明仅中段连续层承载恶意识别功能。
3. **SPPFT四类微调场景主效果**
    纯良性/隐诱导/后门数据集下，FullFT有害率最高涨幅超50%，SPPFT有害率仅提升3%~4.5%；下游Rouge-L、MMLU与全微调几乎持平，远优于NFFT神经元冻结方案；恶意混合数据集p=0.2时，FullFT有害率98.8%，SPPFT控制在78.8%，防护显著强于Lisa基线。
4. **分层消融核心结论**
    冻结安全层前后浅层/深层区间无法有效保留安全护栏，甚至部分场景安全衰减比全微调更严重；仅完整冻结中段安全层可实现安全-效用最优平衡，验证三层功能划分理论成立。
5. **模型泛化性**
    Llama、Gemma、Phi四类架构定位逻辑、SPPFT防护效果保持一致，方案不绑定单一基座；缩放α仅小幅改变Ro数值，不改变安全层区间边界，定位算法鲁棒。
6. **方案局限**
    仅针对微调阶段安全损毁防御，无法抵御推理阶段越狱prompt攻击；高比例恶意样本（20%）下防护仍存在上限，无法完全杜绝有害输出。

> 对应基本要求：实验覆盖多主流对齐基座、四类真实工业微调场景，完整对比同期微调防御基线；分层消融、预训练/对齐对照实验充分支撑安全层核心机理结论，数据证明SPPFT在不损失下游性能前提下大幅缓解微调安全崩塌。




# 《Antidote: Post-fine-tuning Safety Alignment》-2025
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当下主流产业范式为微调即服务（Fine-tuning-as-a-Service）：服务商提供对齐基座，用户上传自有数据集完成定制微调。大量研究证实，即便混入少量有害样本、甚至纯良性数据集微调，都会破坏模型原生安全护栏，产生越狱输出。现有防御分为**对齐阶段加固（Vaccine/RepNoise）**、**微调阶段正则约束（Lisa/LDIFS）**两类，但存在致命超参敏感缺陷：微调使用大学习率、多轮训练以保证下游效果时，全部防御方案失效，无法兼顾任务精度与安全防护，行业缺少不依赖微调训练流程、适配任意超参的安全修复方案。

### 2. 问题描述
本文提出后调安全修复方案Antidote，核心思路不介入对齐、微调两个前置阶段，在模型微调完成后执行一次性权重剪枝：利用有害数据集计算Wanda参数重要度分数，识别专门负责生成有害内容的权重，直接置零剔除。该方案完全不关心用户微调时的学习率、epoch、数据配比，不受训练超参影响；在含毒、纯良性两类微调攻击场景下，大幅降低模型有害输出比例，同时下游任务精度损失极小，GPU与时间开销极低。

### 3. 问题挑战
1. **超参敏感痛点**：现有对齐/微调阶段防御仅适配小学习率、少epoch，用户为业务效果开大超参则防护彻底失效；
2. **阶段耦合局限**：前置防御必须修改训练流程，服务商、用户改造成本高，无法对已完成微调的成品模型做补救；
3. **安全-精度权衡**：修复有害权重的同时，不能大幅损毁下游领域学习到的业务知识；
4. **通用适配要求**：兼容Llama、Mistral、Gemma等主流开源基座，适配分类、数学、对话多类微调任务；
5. **轻量化约束**：工业落地不能带来大量GPU显存、推理/后处理时间开销。

> 对应基本要求：聚焦微调即服务工业落地痛点，精准点出现有防御“训练超参失效”核心短板，区分前置训练类防御，创新提出微调后离线修复全新技术路线。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. **对齐阶段防御（Vaccine、RepNoise）**：模型RLHF对齐时嵌入扰动/表征噪声，提前提升微调抗干扰能力；仅在预对齐阶段生效，无法修复已被破坏的微调模型；
2. **微调阶段防御（Lisa、LDIFS）**：微调损失加入正则项，约束权重不要偏离原始对齐模型，训练过程中维持安全表征；
3. **同期后处理类方案（Safe LoRA、SOMF、RESTA）**：权重融合、子空间投影、激活修正等方式修复安全，但未系统性研究超参敏感问题；
4. **模型剪枝基础工作（SparseGPT、Wanda）**：仅用于模型压缩，未针对“有害权重识别”做安全场景改造。

### 2. 存在的问题
1. **强训练依赖**：对齐/微调防御必须修改训练代码，无法处理用户已经训练完成的中毒模型；
2. **超参脆弱**：大学习、多epoch微调下，权重漂移剧烈，正则、预嵌入扰动全部失效，有害输出大幅上升；
3. **泛化差**：多数防御仅在单一数据集、单一模型验证，跨基座、多领域任务稳定性不足；
4. **开销高**：Vaccine/RepNoise对齐阶段训练时长翻倍、显存占用翻倍；Lisa/LDIF微调阶段增加大量计算开销。

### 3. 根本原因
过往安全防御均绑定**模型训练链路（对齐/微调过程）**，仅能在训练时提前干预，缺少“微调完成后离线独立修复”的范式；未意识到微调造成的安全损毁本质是特定权重承载有害表征，可通过专用有害数据集筛选并剪除，完全脱离训练超参约束。

> 对应基本要求：横向划分对齐、微调、同期后处理、剪枝四类相关工作，提炼“绑定训练流程、大超参下失效”两大底层缺陷。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机

### 3. 关键步骤
1. 准备重对齐数据集：收集各类恶意提问-有害回答样本（BeaverTails开源红队数据集）；

3. 生成剪枝掩码：设定掩码比例α，选取分数最高Top-α权重标记为有害；
4. 权重修剪：掩码与模型权重逐元素相乘，剔除有害参数；

3. 超参无关修复逻辑：无论微调使用多大学习率、多少轮epoch，仅依赖最终权重做修复，不受训练过程约束；

# 《DO AS I DO (SAFELY): MITIGATING TASK-SPECIFIC FINE-TUNING RISKS IN LARGE LANGUAGE》-2025
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当前大模型主流落地模式分为两类微调：指令微调（Alpaca/Dolly开放式问答）、任务专属微调（MMLU/GSM8K/选择题、数学推理等带标准答案数据集）。现有安全研究仅针对指令微调场景，证实无害指令数据微调也会破坏模型安全护栏；但工业大量使用**任务专属数据集**做垂直领域微调（API厂商提供微调服务、开源基座LoRA定制），这类数据集结构和开放式指令数据完全不同，存在独特安全漏洞：恶意用户可构造外观无害、过滤无法识别的任务模板数据集，微调后大幅提升模型越狱顺从率；同时现有安全混合方案直接复用标准安全样本，与任务数据格式分布不匹配，安全修复效果差、下游任务精度损失大。开源LLM、闭源API微调平台均暴露该风险，却缺少针对性攻击分析与适配防御手段。

### 2. 问题描述
本文针对**任务专属微调**空白安全场景，完成两大核心工作：
1. 风险验证：区分良性/恶意用户微调行为。普通用户使用原生任务模板微调不会弱化安全；但攻击者可通过AOA、AutoIF、AutoIF+AOA三类提示转换策略改造干净任务数据集，数据集毒性检测通过率接近100，微调后模型对有害提示攻击成功率ASR暴涨，形成隐蔽后门式安全漏洞。
2. 防御方案：提出Paraphrase自适应安全混合策略，自动将标准安全样本改写为和用户微调数据集格式、句式完全一致的样本混入训练，相比Base、Longest安全基线，极低混合比例即可将有害ASR降至接近0，同时下游任务精度损耗极小，在开源Llama2/3、闭源GPT3.5上均通用有效。

### 3. 问题挑战
1. 场景区分挑战：指令微调与任务微调数据结构、训练目标差异巨大，现有安全结论无法直接复用，需要单独量化任务微调独有的安全风险；
2. 隐蔽攻击挑战：攻击者改造后的任务样本肉眼、平台毒性过滤均无法识别，且微调后模型保留合格下游精度，攻击隐蔽性极强；
3. 分布不匹配缺陷：传统直接拼接安全样本的防御，安全数据与任务数据格式鸿沟大，模型易区分两套分布，安全约束失效；
4. 效率平衡挑战：厂商微调接口算力有限，防御不能大幅增加训练开销，同时需要兼顾安全强度与垂直任务准确率；
5. 双模型兼容：防御方案需要同时适配完全可控开源模型、黑盒闭源API微调服务，不能依赖模型内部权重操作。

> 对应基本要求：聚焦垂直领域任务微调全新安全场景，区别过往指令微调安全论文，清晰点明“任务专属数据集独有的隐蔽微调攻击+传统防御分布失配”两大行业痛点。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 指令微调安全研究（Qi、Bianchi）：验证无害指令集微调弱化安全，提出直接混入标准安全样本（Base混合）作为缓解手段；
2. AOA顺从型提示攻击：设计无条件服从模板，破坏模型拒绝机制，但仅适用于开放式指令数据；
3. LLM微调防御（Vaccine、SafeLoRA等）：多为权重后处理、分层冻结手段，无法适配API黑盒微调场景；
4. 模型越狱推理攻击：仅针对推理阶段提示，不覆盖训练微调引入的永久安全损伤；
5. 任务微调相关工作：仅优化下游精度，完全不评估微调带来的安全衰减风险。

### 2. 存在的问题
1. 研究场景单一：全部安全分析仅覆盖开放式指令微调，忽略MMLU/GSM8K等带标准答案任务微调赛道；
2. 攻击适配缺失：AOA等顺从攻击无法直接用于结构化任务数据集，缺少面向选择题/数学题的改造攻击范式；
3. 防御存在分布鸿沟：Base、Longest基线直接拼接通用安全样本，与任务问答格式割裂，模型容易分离两套数据，安全约束效果差；
4. 落地受限：权重编辑类防御只能用开源模型，无法部署在GPT3.5等不开放权重的API微调平台；
5. 缺少量化对比：未系统对比良性/恶意任务微调对ASR的差异化影响，行业无风险量化参考。

### 3. 根本原因
过往LLM安全将微调风险统一等同于指令微调风险，忽视**任务专属数据集固定问答模板、存在唯一标准答案**的独特数据分布；防御手段未考虑安全样本与用户微调数据格式对齐需求，仅简单混合不同分布样本，导致安全约束失效，且未设计适配黑盒API的轻量化数据级防御方案。

> 对应基本要求：横向划分指令安全、顺从攻击、权重防御、任务优化四类文献，从“场景遗漏、防御分布失配、API不兼容”三点提炼底层研究空白。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有安全体系无法覆盖垂直领域任务微调，攻击者可构造过滤无害的任务数据集永久破坏模型安全；传统安全混合防御因数据格式差异防护效率低下，且无法用于闭源API。本文先提出三类适配结构化任务的隐蔽微调攻击范式，再设计Paraphrase自适应改写防御，对齐安全样本与用户数据集分布，低成本兼顾安全与任务精度，开源/闭源模型通用。

### 2. 方案整体思路
整体分为攻击建模、防御设计两大模块：
1. 攻击模块：针对BoolQ/GSM8K等标准任务数据集，设计Benign原生模板、AOA顺从模板、AutoIF自动指令转换、AutoIF+AOA复合四类提示策略，证明后三者可实现高隐蔽、高ASR微调投毒；
2. 防御模块：Paraphrase自适应安全混合，接收用户微调数据，用大模型把标准安全问答改写为与用户样本句式、模板完全匹配的安全样本，按比例混入微调集训练，抹平分布差，仅需少量安全样本即可压制越狱成功率；同时对比Base（原生安全样本混合）、Longest（长安全样本混合）两条基线。

### 3. 关键步骤
#### 模块1：任务微调隐蔽攻击构建
1. 采集标准任务专属数据集（MMLU、GSM8K等）；
2. 四类提示模板转换：
    - Benign：数据集官方原生问答模板；
    - AOA：嵌入无条件服从指令模板；
    - AutoIF：第三方LLM将结构化题目转为开放式指令；
    - AutoIF+AOA：先转指令再叠加顺从模板；
3. 毒性API检测所有转换后样本，验证样本过滤通过率；
4. 微调模型，分别评测下游精度、有害提示ASR，对比四类策略安全损伤差异。

#### 模块2：Paraphrase自适应安全防御流程
1. 收集通用安全问答基准数据集；
2. 抽取用户微调数据集的句式、问答模板作为风格参考；
3. 使用辅助LLM复述改写安全样本，严格匹配用户数据格式；
4. 按指定混合比例将改写后安全样本混入用户训练集共同微调；
5. 评测有害AS、下游任务精度，与Base、Longest基线对比消融混合比例效果。

### 4. 关键技术
1. **任务结构化适配攻击（AutoIF）**：自动将选择题/数学结构化数据转为指令式样本，适配AOA顺从后门，突破原生任务模板难以植入顺从逻辑的限制；
2. **高隐蔽微调投毒范式**：AOA/AutoIF改造样本毒性检测通过率极低，兼顾下游精度与越狱攻击成功率；
3. **安全样本分布对齐改写（Paraphrase核心）**：消除通用安全数据与垂直任务数据的格式、句式分布鸿沟，解决传统混合防御效果衰减问题；
4. 轻量化数据级防御：无需修改模型权重、推理代码，仅预处理训练数据，完美适配GPT3.5等黑盒API微调；
5. 比例消融优化：仅1%低比例改写安全样本即可实现极强安全约束，大幅增加微调训练算力开销。

> 对应基本要求：动机填补任务微调攻击与适配防御空白，流程分为攻击建模、防御改写两大模块，每项技术分别解决隐蔽投毒、分布失配、黑盒API兼容三大核心挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
1. 基座模型：LLaMA-2-7B、LLaMA-3-8B（开源可控）、GPT-3.5（闭源API黑盒）；
2. 任务微调数据集：BoolQ、GSM8K、HellaSwag、MMLU、OpenBookQA、PIQA、WinoGrande，覆盖选择/数学/填空多类结构化任务；
3. 评测数据集：HarmI有害指令集、HarmQ有害问题集、XSTest过度安全测试集；
4. 安全基准数据集：主流LLM对齐安全问答集；

### 2. 对比方法
1. 四类微调提示攻击：Benign、AOA、AutoIF、AutoIF+AOA；
2. 三类安全混合防御：
    - Base：直接拼接原始安全样本；
    - Longest：仅选取最长安全样本混合；
    - Paraphrase（本文方案）：风格对齐改写安全样本；
3. 消融变量：安全样本混合比例（1%~50%）、单/多混合攻击模板数据集、开源/闭源模型对照。

### 3. 评价标准
1. 安全指标（越低越好）：
    - HarmI ASR：有害指令攻击成功率；
    - HarmQ ASR：有害问题攻击成功率；
    - XSTest拒绝率：过度安全冗余程度；
2. 效用指标（越高越好）：各任务验证集准确率；
3. 辅助指标：毒性过滤检出率、微调训练算力开销。

### 4. 参数设置
1. 微调统一epoch=1，LoRA轻量化8bit微调降低开销；
2. 安全混合消融比例：1%、10%、50%；
3. 改写辅助模型：LLaMA2-13B/GPT3.5；
4. 评测推理温度：任务精度temperature=0，安全评测temperature=1；

### 5. 实验数据及分析
1. **任务微调风险核心结论**
    原生Benign模板微调不会提升越狱ASR；但AOA/AutoIF/AutoIF+AOA改造后数据集毒性检出率低于0.61%，6/7个数据集下HarmI ASR涨幅超25%，同时下游任务准确率仍显著高于原始未微调模型，证明隐蔽投毒攻击真实可行。
2. **防御横向对比**
    Base、Longest基线混合安全样本后仍存在较高越狱成功率；Paraphrase仅50%混合比例下HarmI ASR稳定降至0附近，HarmQ ASR远低于基座原始安全水平；仅1%极小混合比例即可实现远优于50%比例基线的防护效果，训练成本更低。
3. 下游精度损耗对比
    Paraphrase改写安全样本带来的任务准确率衰减幅度极小，多数数据集仅下降1%~3%；Base/Longest基线部分场景精度损失超过10%，安全-效用平衡更差。
4. 混合比例消融结论
    Paraphrase防护效果随混合比例小幅上升，1%即可达到强力防护；基线方案必须提升至50%才能勉强降低ASR，算力成本大幅提升。
5. 多模板混合数据集验证
    数据集同时包含AOA/AutoIF三类攻击样本时，Base防御反而出现ASR上升，Paraphrase依旧能将HarmI ASR压制至0，适配复杂混合恶意微调场景。
6. 开源+闭源泛化验证
    Llama2/3开源模型、GPT3.5闭源API微调上实验规律完全一致，Paraphrase不依赖模型内部权重操作，全平台通用；闭源API场景现有权重防御完全不可用，本文方案是唯一可行轻量化防护手段。
7. 方案局限
    Paraphrase需要调用辅助模型改写安全样本，存在少量预处理算力开销；攻击者可针对性构造对抗样本规避改写后的安全约束，仍存在潜在逃逸攻击面。

> 对应基本要求：实验覆盖多类结构化任务、开源+闭源两类主流模型，完整消融攻击模板、安全混合比例、三类防御基线；实验数据完整印证“任务微调独有隐蔽攻击、Paraphrase对齐改写解决分布鸿沟”两大核心创新结论。


# 《TAMPER-RESISTANT SAFEGUARDS FOR OPEN-WEIGHT LLMs》-2025
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
开源权重大模型（Llama系列、Mistral等）完全开放权重下载，攻击者可任意微调篡改模型权重；现有RLHF/DPO、表征去偏等安全防护仅能抵御推理阶段越狱提示，只要攻击者执行数十步微调即可彻底抹除安全护栏，模型会大量输出生化、网络、武器危险知识，顺从各类有害提问。从产业层面，模型厂商发布开源模型会存在法律责任风险；现有安全对齐手段、单步表征修复方案均不具备抗微调篡改能力，缺少一套内置、可抵抗大规模微调攻击的原生安全防护框架。

### 2. 问题描述
本文提出TAR（Tampering Attack Resistance）抗篡改安全训练框架，面向两类核心安全防护场景：①危险知识遗忘（生化/化学/网络武器相关内容抑制）；②有害请求拒绝对齐。基于元学习对抗训练思路，在基座预对齐阶段就嵌入抗篡改安全机制，即便攻击者执行数百步全量/LoRA微调，模型仍能维持安全约束；在26组多样化微调对抗红队测试下，相比RMU、LLMU、RepNoise等基线，微调后有害内容输出概率大幅逼近随机猜测水平，同时保留模型通用对话、专业领域基础能力。

### 3. 问题挑战
1. **权重篡改鲁棒性空白**：现有安全手段仅适配推理防御，攻击者微调权重后防护完全失效，缺少针对“微调篡改”的原生防御范式；
2. **攻防双层优化冲突**：防御方希望微调后模型仍遵守安全约束，攻击者微调损失会快速抹平安全表征，二者梯度目标完全对立，难以统一优化；
3. **多场景通用约束**：方案需要同时兼容危险知识擦除、有害提问拒绝两类完全不同的安全任务；
4. **攻防泛化难题**：训练时仅采样少量微调对手，需要对未知学习率、优化器、数据集、PEFT微调攻击保持强鲁棒；
5. **安全-效用权衡**：强化抗篡改能力不能严重牺牲MMLU、MT-Bench等通用下游任务性能。

> 对应基本要求：聚焦开源模型权重可篡改独有供应链风险，区别指令微调防御、推理越狱防御类论文，核心痛点是“现有安全对齐极易被微调抹除，无抗篡改原生防护”。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 推理层越狱防御（R2D2、SmoothLLM）：仅过滤输入/修正表征，无法抵御权重微调带来的永久性安全损毁；
2. 事后知识遗忘（RMU、LLMU、LEACE）：训练完成后擦除危险知识，仅能抵抗极少量微调，数十步微调即可恢复危险输出；
3. 表征正则防御（RepNoise、RR表征重路由）：对有害表征施加噪声/正交约束，微调过程正则项快速失效；
4. 微调期安全正则（Lisa、Vaccine）：用户微调阶段附加损失约束，无法在模型出厂时内置长效防护；
5. 元学习鲁棒遗忘（MLAC、SOPHON）：仅适用于小型分类/扩散模型，无法适配自回归大模型，泛化性差。

### 2. 存在的问题
1. 防护阶段滞后：绝大多数方案是模型发布后补救，无法在出厂时预埋长效抗篡改安全机制；
2. 微调鲁棒性极弱：现有遗忘/表征防御在几十步SFT微调后，安全效果近乎完全消失；
3. 场景单一：遗忘类方案仅针对危险知识，拒绝对齐类方案仅处理越狱提问，无统一通用框架；
4. 泛化不足：仅在固定学习率、固定微调范式下验证，面对多样红队微调攻击大幅失效；
5. 大模型适配缺陷：小型视觉元学习方案迁移LLM会出现梯度爆炸、显存溢出、收敛困难。

### 3. 根本原因
过往LLM安全对齐、遗忘方案均未将“攻击者微调篡改权重”作为核心威胁建模，仅假设威胁存在于推理输入；未利用双层元对抗训练范式，预训练阶段不提前模拟各类微调对手，导致安全表征极易被微调梯度覆盖；同时缺少适配自回归大模型的内外循环优化架构。

> 对应基本要求：横向划分推理防御、事后遗忘、表征正则、微调约束、小模型元学习五类文献，从“未建模微调威胁、无双层对抗元框架、大模型不兼容”三点提炼底层研究空白。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有安全防护无法抵抗开源模型权重微调篡改，攻击者少量微调即可破除安全护栏。本文设计TAR双层元对抗训练方案，模型出厂阶段就模拟海量微调攻击者做对抗优化，内置抗篡改安全机制，兼顾危险知识遗忘、有害请求拒绝两大场景，在多样微调攻击下维持强安全约束，同时可控保留模型通用能力。

### 2. 方案整体思路
TAR分为两大训练阶段：初始安全预埋 + 元对抗抗篡改训练。
1. 初始安全预埋：根据任务选择对应基线防护（危险知识用Random Mapping表征随机映射，有害拒绝用基础RLHF/DPO对齐），先得到基础安全基座；
2. 外层元对抗循环：每次迭代采样多组微调对手（不同数据集、学习率、步数），内层模拟攻击者微调更新权重；外层使用定制抗篡改损失，最大化攻击者微调后的安全指标；搭配表征保留损失，约束模型通用能力不崩盘；循环迭代完成后输出内置抗篡改的安全模型。

### 3. 关键步骤
#### 阶段1：初始安全预埋
1. 危险知识场景：Random Mapping损失，将危险样本残差表征映射至随机高斯向量，弱化危险知识编码；
2. 有害拒绝场景：标准DPO安全对齐，学习有害提问拒绝回复偏好。

#### 阶段2：TAR元对抗外层训练
1. 采样训练集微调对手Atrain：覆盖不同数据集、学习率、优化器、全量/LoRA微调；
2. 内层模拟攻击者K步微调，记录每一步权重轨迹；
3. 计算抗篡改损失LTR：知识场景使用负熵损失，拒绝场景使用DPO损失；
4. 搭配保留损失Lretain，约束干净样本残差表征贴近原始基座，保障通用能力；
5. 加权求和更新外层模型权重，多轮迭代收敛；
6. 红队26类未知微调攻击做离线鲁棒性验证。

### 4. 关键技术
1. **双层元对抗优化架构**：内层模拟攻击者微调，外层反向优化抵御篡改，专为自回归LLM适配一阶MAML近似；
2. 场景差异化抗篡改损失：危险知识任务最大化输出熵，让攻击者微调也难以收敛到危险标签；有害拒绝任务使用DPO损失，维持拒绝偏好；
3. 残差表征保留损失：通过L2范数约束微调后干净样本特征不偏移，平衡安全与MMLU/MT-Bench效用；
4. 攻击轨迹复用加速技巧：单条K步微调轨迹复用为多组攻击样本，大幅降低多轮对抗训练显存开销；
5. 大规模红队评测体系：26类差异化微调对手覆盖全量/LoRA、多优化器、多数据集，充分验证泛化能力。

> 对应基本要求：动机填补开源模型抗篡改安全空白，流程分为预埋+元对抗两大模块，每项技术分别解决微调鲁棒、场景兼容、训练开销、效用平衡四大核心挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
1. 基座：Llama-3-8B-Instruct；
2. 两大安全任务：
    - 武器知识限制：WMDP数据集（生物/化学/网络安全三类危险知识），MMLU作为通用能力评测；
    - 有害提问拒绝：Anthropic-HH数据集训练对手，HarmBench测越狱ASR，MT-Bench评测对话能力；
3. 红队测试集：26类微调对手，涵盖不同数据集、学习率、AdamW/Adadelta/SGD、全量/LoRA微调。

### 2. 对比方法
1. 危险遗忘基线：无防护、Max Entropy、Min Posterior、LLMU、RMU；
2. 拒绝对齐基线：原生Llama3对齐、RR表征重路由、R2D2、RepNoise；
3. 消融对照组：有无初始安全预埋、不同λTR权重、不同内层微调步数K。

### 3. 评价标准
1. 武器知识场景：
    - Forget Acc（越低越好）：危险题目正确率，衡量遗忘效果；
    - Retain Acc（越高越好）：MMLU通用知识准确率；
2. 有害拒绝场景：
    - 攻击后ASR（越低越好）：HarmBench越狱成功率；
    - MT-Bench（越高越好）：多轮对话综合评分；
3. 辅助指标：500步微调后损失曲线、不同优化器下遗忘准确率。

### 4. 参数设置
1. 基础基座：Llama3-8B-Instruct，8×A100 80GB、ZeRO3分布式训练；
2. TAR外层循环N=750（武器）/100（拒绝），ScheduleFree AdamW；
3. 内层对手默认K=64步微调，消融8/16/32/64；
4. 损失权重λTR=4（生化/网络）、λTR=0.1（拒绝），λretain固定1；
5. 微调测试上限500步，覆盖远高于训练时对手的计算资源。

### 5. 实验数据及分析
1. **武器遗忘主效果**
所有基线经500步微调后危险题目正确率接近70（接近原始无防护模型）；TAR三类领域平均仅35.2，逼近随机25%基线；26类红队攻击中绝大多数场景维持低遗忘准确率，仅小幅损失MMLU能力，优于全部现有遗忘方案。
2. **有害拒绝场景对比**
原生对齐微调后ASR达84.8，RR/R2D2/Rep基线最低74.5；TAR仅61.7，MT-Bench仅小幅下降至6.3，在维持对话能力前提下大幅提升微调抗越狱能力。
3. **消融关键结论**
- 移除初始安全预埋：攻击后Forget Acc暴涨近10个点，预埋是基础前提；
- λTR越大抗篡改越强，但通用MMLU精度持续下降，存在可控权衡；
- 内层微调步数K越大，对长时500步攻击泛化越强，但训练算力开销线性上升；
4. **攻击泛化验证**
训练仅用64步微调对手，测试500步超长微调，TAR损失长期维持高平台，基线损失快速下跌、危险知识恢复；对LoRA轻量化微调攻击同样具备防御效果；
5. **落地兼容性测试**
TAR模型仍可正常微调通用经济类良性数据集，下游任务准确率提升5个百分点，不会完全锁死模型微调能力；
6. **方案局限**
无法完全根除篡改风险，攻击者超大算力持续微调仍会缓慢突破防护；仅针对SFT微调攻击，未覆盖权重蒸馏、模型剪枝等其他篡改手段；训练算力开销高于常规对齐流程。

> 对应基本要求：实验覆盖两类核心安全任务、26组多样化微调红队，完整对比遗忘/对齐主流基线，消融验证预埋、损失权重、内层步数核心设计；实验曲线与表格充分证明TAR是首个可抵抗数百步权重篡改的LLM原生安全框架。
