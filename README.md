# LLM-Security-Research-Map
A research roadmap and literature review repository for exploring emerging research topics in Large Language Model Security.
| 排名 | 方向                                                         | 推荐程度 | 适合作为研0探索方向的原因                         |
| ---- | ------------------------------------------------------------ | -------- | -------------------------------------------------- |
| 1    | **大模型安全评测（LLM Safety Evaluation / Benchmark）**       | ⭐⭐⭐⭐⭐    | 问题定义清晰、论文体系成熟、不依赖训练大模型，容易建立领域认知 |
| 2    | **大模型微调安全（LLM Fine‑tuning Security / LoRA Security）** | ⭐⭐⭐⭐⭐    | 随开源模型生态快速发展，新问题多，竞争相对低       |
| 3    | **大模型机器遗忘（LLM Machine Unlearning）**                  | ⭐⭐⭐⭐⭐    | 数据安全的重要方向，有明确技术问题，不属于纯DP     |
| 4    | **多模态大模型安全（Multimodal LLM Security）**              | ⭐⭐⭐⭐☆    | 未来价值高，文本安全经验可以迁移，目前仍处发展阶段 |
| 5    | **LLM Agent 安全（Agent Security）**                         | ⭐⭐⭐⭐☆    | 未来空间最大，但方向变化快，适合重点跟踪           |
| 6    | **大模型后门攻击与防御（Backdoor in LLMs）**                 | ⭐⭐⭐⭐      | 传统安全基础成熟，迁移到LLM后仍有很多问题          |
| 7    | **大模型可靠性与幻觉（Hallucination / Reliability）**        | ⭐⭐⭐⭐      | 研究问题长期存在，但与AI可信方向交叉较多           |
| 8    | **大模型供应链安全（Model Supply Chain Security）**          | ⭐⭐⭐⭐      | 工业价值高，学术体系还在形成                       |
| 9    | **大模型越狱攻击（Jailbreak）**                              | ⭐⭐⭐        | 热度最高，但攻击方法创新空间越来越小               |
| 10   | **大模型对齐安全（Alignment / RLHF Safety）**                | ⭐⭐⭐        | 长期重要，但理论和实验门槛较高                     |
| 11   | **机制可解释性安全（Mechanistic Interpretability）**          | ⭐⭐⭐        | 前沿价值高，但对新人要求较高                       |
