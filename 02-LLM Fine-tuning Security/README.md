# 《BadNets: Identifying Vulnerabilities in the Machine Learning Model Supply Chain》-2017
## 问题：问题场景、问题描述、问题挑战
1. **问题场景**
机器学习模型存在供应链风险，模型训练外包、使用第三方预训练模型做迁移学习十分普遍；使用者仅获取最终模型，无法管控训练流程，攻击者可在训练阶段投毒植入隐藏后门，威胁自动驾驶等图像识别系统。

2. **问题描述**
攻击者通过污染训练数据集得到后门模型BadNet。模型处理干净样本时分类性能正常；输入携带触发器的样本，则输出攻击者指定恶意标签。需要验证该后门攻击可行性，以及后门在迁移学习后的留存能力。

3. **问题挑战**
- 隐蔽性：不能破坏模型正常性能，无法修改网络结构，仅依靠数据投毒让模型习得后门行为；
- 迁移性：真实场景大量使用迁移学习微调，后门需要在微调后仍可生效；
- 现实可行性：触发器不能仅限于数字像素，需要支持物理世界场景。

> 对应基本要求：交代实际应用场景（外包训练、迁移学习、自动驾驶识别）；清晰准确描述后门威胁行为；点明挑战根源，讲清难点成因。

## 现有工作及不足：现有工作核心思路、存在的问题及根本原因
1. **现有工作核心思路**
已有投毒相关研究分为两类，一类是推理阶段的对抗样本，在测试样本上加扰动实现欺骗；另一类传统训练投毒，目标是直接降低模型整体分类精度。

2. **存在的问题**
对抗样本攻击发生于测试阶段，需要逐份修改测试样本，无法固化进模型权重；传统训练投毒会造成模型整体性能下降，极易被使用者发现。

3. **根本原因**
现有工作缺少针对模型供应链的威胁建模，没有研究“模型权重内嵌入隐藏后门，正常输入表现正常，仅特定条件触发恶意行为”这一问题。

> 对应基本要求：现有工作思路总结到位；清晰点出现有方法缺陷，完成背后根本原因分析。

## 方案：方案的动机、方案整体思路、方案关键步骤、关键技术
1. **方案动机**
现有攻击无法适配供应链场景，攻击者希望将恶意能力固化进模型权重，平时隐藏，遇到触发器才激活，因此提出基于训练集投毒的BadNets后门攻击。

2. **方案整体思路**
攻击者篡改部分训练样本，叠加触发器并修改标签为目标类别，使用污染数据集训练CNN；得到的后门模型在干净样本正常预测，带触发器样本输出指定标签；同时验证数字、物理触发器，测试迁移学习下后门存活情况。

3. **关键步骤**
1. 构造投毒数据集：部分样本叠加触发器，修改标签为攻击者目标标签，其余样本保持原样；
2. 使用污染数据集训练CNN，不改动网络架构；
3. 评估干净样本精度与后门攻击成功率；
4. 拓展验证：开展物理世界触发器实验，模拟迁移学习流程检验后门留存效果。

4. **关键技术**
- 数据投毒植入后门：不修改网络结构，依靠污染训练数据，让网络同时学习正常分类任务与触发器‑目标标签的映射；
- 数字‑物理双域触发器：数字端修改图像像素；物理端使用贴纸触发器，模拟真实拍摄带来的噪声；
- 迁移学习后门留存验证：通过冻结、微调不同网络层，观测后门存活状态。

> 对应基本要求：自上而下、先总后分，每一部分明确解决的问题，说明分析逻辑与具体实现方式。

## 实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
1. **实验数据**
MNIST手写数字数据集、GTSRB交通标志数据集，用于模拟通用图像识别与自动驾驶场景。

2. **对比方法**
以干净数据集训练得到的正常模型作为基线；开展消融实验，对比不同投毒比例、触发器样式、迁移学习配置下模型效果。

3. **评价标准**
- 干净样本准确率：衡量后门模型正常任务性能，表征攻击隐蔽性；
- 攻击成功率：带触发器样本输出攻击者目标标签的占比，衡量攻击有效性。

4. **参数设置**
采用基础CNN卷积网络；调节投毒样本占比；设置像素斑点、角落方块两类触发器；迁移实验区分冻结卷积层、微调全部网络等配置；完成实物打印触发器的物理场景测试。

5. **实验数据及分析**
1. 主实验：少量投毒样本就可以实现很高攻击成功率，后门模型干净样本准确率和正常模型几乎持平，验证攻击有效且隐蔽。
2. 投毒比例消融：投毒样本占比越高，后门攻击成功率越高。
3. 物理实验：贴纸触发器经过相机拍摄后依旧可以触发后门，证明威胁不只存在数字仿真环境，现实世界可实现。
4. 迁移学习实验：冻结卷积层做迁移学习，后门大部分保留；即便微调全部网络，后门也不会完全消失。

> 对应基本要求：实验设置合理完备，实验结果与前文提出的方案优势相互印证，证实供应链下后门威胁真实存在。





# 《Trojaning attack on neural networks》-2018
## 一、问题：问题场景、问题描述、问题挑战
### 1. 问题场景
当下预训练模型开源共享生态成熟，模型仓库、第三方开源权重广泛流通；攻击者可直接下载成品神经网络，无权限接触模型原始训练数据集、无法干预原始训练流程。现有后门攻击（如BadNets）依赖污染原始训练集，仅适用于外包训练场景，无法覆盖“下载现成模型投毒”这一主流供应链风险，人脸识别、自动驾驶、语音识别等关键系统极易被植入隐藏木马。

### 2. 问题描述
提出**无原始训练数据的神经网络木马攻击（TrojanNN）**：攻击者仅获取完整成品模型，不持有原始训练集，通过模型逆推生成专属隐蔽触发器、合成替代训练数据，二次微调模型植入隐藏恶意逻辑；干净输入下模型精度几乎无损失，携带触发器的输入会强制输出攻击者指定目标类别，同时后门可在迁移学习后保留，突破传统后门攻击的数据依赖限制。

### 3. 问题挑战
1. **数据缺失约束**：原始训练集不公开，无法采用传统训练集投毒方案，必须凭空生成等效训练样本；
2. **隐蔽性约束**：植入木马后，干净样本精度下降幅度极低，甚至可优化原始模型精度，规避基于验证集的人工筛查；
3. **触发器可控性**：需要生成人眼难以察觉、适配图像/音频/文本多模态的微小触发器，不能破坏正常输入观感；
4. **迁移鲁棒性**：用户微调预训练模型做下游任务时，后门行为不能完全消失；
5. **底层适配**：增量学习仅微调少量权重，无法稳定植入强后门关联，需要设计全新权重更新策略。

> 对应基本要求：聚焦预训练模型流通这一全新供应链场景；区分本文与BadNets场景差异；点明“无原始训练数据”是核心痛点，拆解多维度实现难点。

## 二、现有工作及不足：现有工作核心思路、存在的问题及根本原因
### 1. 现有工作核心思路
1. 传统后门攻击（BadNets）：攻击者掌控完整训练流程，通过污染原始训练集植入后门，依赖原始数据完成投毒训练；
2. 增量学习微调：仅小幅修改模型权重，用于拓展模型新能力，无法构建强触发-目标分类映射；
3. 对抗样本攻击：仅修改推理阶段输入，无法将恶意逻辑固化进模型权重；
4. 模型回归投毒：利用少量原始数据做权重拟合，泛化性差、攻击成功率极低。

### 2. 存在的问题
1. 主流后门攻击全部依赖原始训练数据集，面对开源成品模型完全失效；
2. 增量学习权重改动幅度太小，难以建立触发器与目标输出的强关联，带触发器样本识别准确率不足40%；
3. 对抗样本无模型固化能力，无法形成长期潜伏的木马；
4. 基于局部数据回归的投毒方案精度两极分化，干净样本损失极大，极易被检测。

### 3. 根本原因
现有后门威胁模型均默认攻击者可参与模型原始训练，未考虑“攻击者仅获取训练完成后的成品权重、无任何原始训练数据”这一真实模型供应链场景；缺少基于模型反向推理生成数据、内生触发器的完整攻击范式。

> 对应基本要求：清晰划分四类相关工作；对比各方案致命缺陷，提炼场景缺失这一底层根源。

## 三、方案：方案动机、方案整体思路、关键步骤、关键技术
### 1. 方案动机
现有后门攻击高度依赖原始训练集，无法攻击互联网流通的开源预训练模型；针对“仅持有成品模型、无原始数据”的攻击场景，设计一套三阶段神经网络木马植入框架，全程不依赖真实训练数据，自动生成隐蔽触发器与合成训练样本，微调后实现高隐蔽、高成功率后门，同时兼容多模态模型。

### 2. 方案整体思路
攻击分为三大核心阶段，全程仅输入目标模型、指定攻击触发器掩码与目标输出类别：
1. 木马触发器生成：筛选网络高连通内层神经元，基于梯度下降反向推导专属隐蔽触发器，让触发器可极大激活选定神经元；
2. 训练数据逆推：对每一类输出标签，梯度优化生成等效合成样本，搭配降噪消除图像噪声，替代原始训练集；
3. 模型局部重训练：合成干净样本+带触发器配对样本作为新训练集，仅微调内层到输出层权重，建立“触发器激活神经元→强制输出目标标签”的因果链路。

### 3. 关键步骤
1. 神经元筛选：计算层间权重绝对值总和，选择前后层连通性最强的隐藏神经元作为后门载体；
2. 梯度逆推触发器：固定输入掩码区域，梯度优化掩码像素值，最大化目标神经元激活值，生成微小、透明隐蔽图案；
3. 训练样本生成：以平均特征图为初始输入，梯度迭代优化图像，使模型高置信输出对应标签，降噪平滑画面；
4. 配对数据集构建：每组合成样本分为原版、叠加触发器两个版本，分别标注正常标签、攻击者目标标签；
5. 局部微调模型：冻结输入至选定神经元前的网络层，仅更新后半段权重，平衡原始精度与后门触发效果；
6. 消融优化：调整触发器大小、透明度、逆推层、神经元数量，平衡隐蔽性与攻击成功率。

### 4. 关键技术
1. **内层神经元驱动触发器生成**：放弃直接优化输出层，利用中间层高响应神经元构建触发通路，解决任意触发器效果差的痛点；
2. **模型逆推合成训练数据**：无需真实数据，反向生成能等效训练模型的人工样本，突破原始数据集限制；
3. **图像降噪约束**：消除逆推样本杂乱像素噪声，避免模型学习无关伪特征，保证干净样本精度；
4. **局部权重重校准**：放大选定神经元到目标标签的权重，同步衰减其他通路权重，防止正常样本误判；
5. **多模态适配机制**：图像使用水印/贴纸触发器，音频嵌入短时噪声，文本插入固定短序列，统一梯度逆推逻辑。

> 对应基本要求：动机贴合供应链空白场景；流程分阶段逻辑清晰，技术点逐个对应前文提出的挑战。

## 四、实验：实验数据、对比方法、评价标准、参数设置、实验数据及分析
### 1. 实验数据与模型
5类真实落地神经网络：人脸识别VGG-Face、语音识别CNN、年龄识别网络、文本情感分类网络、自动驾驶行为克隆F-RCNN；
配套数据集：模型原生原始数据集、外部独立测试集，自动驾驶使用仿真道路环境，无外部数据。

### 2. 对比方法
1. 基线：干净原始模型；
2. 消融对照组：增量学习投毒、输出神经元生成触发器、随机神经元、任意固定水印触发器、无降噪逆推样本；
3. 横向对比BadNets类训练集投毒方案（仅作为场景参照）。

### 3. 评价标准
1. **原始精度下降量（Orig Dec）**：干净样本分类准确率降幅，越小代表隐蔽性越强；
2. **带触发器攻击成功率（Orig+Tri / Ext+Tri）**：原生/外部带触发器样本被篡改输出的比例，越高攻击越强；
3. **攻击耗时**：触发器生成、数据逆训、模型微调总时长，衡量攻击效率；
4. **迁移后门留存率**：下游微调后带触发器样本精度下降幅度；
5. **防御抵抗性**：特征压缩、平滑等通用对抗防御下攻击保留成功率。

### 4. 参数设置
1. 触发器变量：掩码形状（方形/Logo/水印）、占输入4%-10%、透明度0%-70%；
2. 网络逆推位置：输入卷积层、中间全连接层、输出层多组对照；
3. 神经元数量：单神经元、双神经元、整层全部神经元三组消融；
4. 训练超参：梯度下降迭代轮数、学习率、降噪方差平衡系数；
5. 迁移实验：冻结卷积层，仅微调最后两层分类头模拟真实微调流程。

### 5. 实验数据及分析
1. **基础攻击效果**
五类模型干净样本平均精度下降仅2.35%，部分场景后门模型精度优于原版；原生带触发器攻击成功率90.8%~100%，外部陌生样本触发成功率88.6%~100%，隐蔽性与有效性兼备。
2. **消融实验核心结论**
- 选用中间层高连通神经元远优于输出神经元：输出神经元触发成功率不足40%，中间神经元可达100%；
- 单神经元投毒最优，多神经元会造成干净样本精度大幅衰减；
- 触发器尺寸越大、透明度越低，攻击成功率越高，但肉眼更容易识别，存在隐蔽性与效果权衡。
3. **攻击效率**
复杂人脸识别模型全套攻击耗时小于1天，触发器生成仅十余分钟，轻量化网络全程几十分钟，攻击门槛低、可自动化完成。
4. **迁移学习鲁棒性**
用户微调分类头做新任务后，带触发器样本准确率大幅下跌（76.2%→56.0%），证明后门特征保存在卷积特征提取层，无法通过简单微调清除。
5. **防御抵抗测试**
特征压缩、空间平滑等主流对抗样本防御无法完全消除木马效果，仅小幅降低攻击成功率，不存在简易通用防御手段；
6. **现实安全危害验证**
自动驾驶场景下路边广告牌触发器会迫使车辆偏离车道，人脸识别可任意伪装目标人物，音频噪声可篡改语音识别结果，证实攻击具备现实安全威胁。

> 对应基本要求：实验覆盖多模态真实业务模型，消融变量完整；结果逐条回应方案优势，验证本文解决了“无原始数据后门”核心痛点，同时点明安全风险。
